# HugEngine GI 对比实验室（06.GILab）规划

> 状态：实现中（已落地核心场景 + GI 对比面板）| 关联：`HugEngine Entity Component 开发计划.md`（渲染体系/GI 路线）
> 目标：一个专门 Sample，用于**检验与对比各种 GI 的实现效果**，并作为**开发新 GI**（实现 `IGlobalIllumination` 接口）的接入/验证试验场。

---

## 一、目标与定位

1. **检验已有 GI**：在同一场景下实时切换/对比 各种 GI（IBL / RSM / SSGI / DDGI / SSR）的视觉效果与性能。
2. **对比基准**：以路径追踪（PT）为 ground truth（后续），量化新 GI 与参考真值的误差与耗时。
3. **开发新 GI**：新 GI 只需实现统一接口（已存在），即可自动接入 Sample 面板做切换/对比/计时——不需要改 Sample 或管线。

## 二、设计方案

| 模块 | 说明 |
|---|---|
| **场景** | Sponza glTF（现有资源，间接光/反射丰富）+ 可切换 Cornell Box 预设（后续） |
| **管线** | DeferredPipeline（GBuffer + 全屏 Lighting，含 SSGI/DDGI/SSR） |
| **GI 对比面板** | IBL 强度 / SSGI（半径/采样数/强度）/ DDGI（探针/时间混合/强度）/ SSR（步数/步长）——切换 + 每 GI 耗时显示 |
| **调试显示** | 只显示各 GI 输出纹理（间接漫反射/镜面分离视图）——后续 |
| **统一接口** | `IGlobalIllumination`（`Engine/Render/GI/GlobalIllumination.h`，继承 `IRenderSubsystem`）——已存在，全部 GI 已继承 |

### 统一接口说明（已存在，非新建）

```cpp
// Engine/Render/GI/GlobalIllumination.h
class IGlobalIllumination : public IRenderSubsystem {
    GIMode GetMode() const;
    const GISettings& GetSettings();
    void SetSettings(const GISettings&);
    GIDebugData GetDebugData() const;                 // 耗时/探针数/内存
    rhi::IRHITexture* GetIndirectDiffuseTexture() const;   // 间接漫反射
    rhi::IRHITexture* GetIndirectSpecularTexture() const;  // 间接镜面
};
// 继承：GI_None / GI_IBL / GI_RSM / GI_SSGI / GI_DDGI / GI_SSR
```

> 新 GI 只需继承 `IGlobalIllumination` 并实现上述方法，即可被 GILab 面板枚举/切换/计时。

## 三、实现现状（已完成）

- **06.GILab Sample**（`Samples/06.GILab/`）：
  - Sponza glTF 场景加载（`LoadGLTF`）
  - DeferredPipeline（含 SSGI/DDGI/SSR）
  - GI 对比面板：IBL 强度 / SSGI / DDGI / SSR 切换 + 参数 + **每 GI 耗时**（`GetDebugData().avgRenderTimeMs`）
  - 相机移动速度默认 **3**（慢速检查场景）
  - 构建接入 `Samples/CMakeLists.txt`
