# D3D12 已知问题与未完成功能

> 整理日期：2026-10-30（分支 `dx12`，最新提交 `7d5e7755`）
>
> 本文是 D3D12 后端的**状态总表**：
> 1. 尚未解决的问题与未完成的功能（每项对应《D3D12剩余任务实施指南.md》里的任务编号 T1～T10）；

## 一、待办：问题与功能

| 任务 | 类别 | 内容 | 现状 |
|------|------|------|------|
| **T2** | 复核 | Lumen 统计与反馈计数的读数 | 已改为确定性回读（`LumenStatsReadback`；反馈槽位 kMaxFramesInFlight + 1）。本机开 Lumen 每帧约 25 秒，统计尚未产出，只验证了编译、调试层 0 报错、帧耗时与改动前一致。需复核 D3D12 与 Vulkan 读数是否一致（原问题：反馈请求数 D3D12 2040 / Vulkan 14）。 |
| **T4** | 缺陷 | Nanite 软光栅在 D3D12 下画面错误 | `nanite_enable=1` + `nanite_soft_raster=1` 时场景几何几乎全部消失、只剩天空 / 远景；只开 Nanite 时正常。已修材质 bindless 数组落错 space（GPU 验证 id=935）与派发超出 65535 上限（id=1497，改二维）；修后 0 报错但画面仍错。疑为第 1 趟深度键没写入，深度解析把整屏写成远平面。 |
| **T6** | 功能 | SM 6.8：用 `SV_StartInstanceLocation` 去掉实例号绕行 | Agility 运行时已就绪；着色器仍按 6.6 编译，实例号经 ShaderToDxil 改成逐实例属性 `HE_INSTANCEINDEX`、读 `kInstanceIndexSlot` 的序号缓冲。 |
| **T7** | 功能 | GPU 驱动的 GBuffer 路径（界面「GPU 视锥剔除 0 可见」） | 剔除本身在工作，但派发后**有意**把可见数清零，让 GBuffer 一直退回 CPU 绘制。直接放开画面错乱，查到三处问题：顶点双重偏移（**已修**）、物体缓冲顺序与 GPU 场景不一致、单级 Hi-Z 遮挡判定不保守。DGC 与间接绘制路径依赖它才能真正验证。 |
| **T8** | 优化 | PSO 预编译 | Vulkan 因本机 Intel 驱动在预编译线程崩溃而关闭了预编译；引擎只有 SSAO 调用 `PrecompileQueuePSO`，覆盖面很小。 |
| **T9** | 缺陷 | 06 截图那一帧偶发后缓冲屏障状态不一致 | `HE_CAPTURE_FRAME` 截图时偶发调试层 id=527（截图列表的起始状态 PRESENT 与实际不符，随后主列表也报一次）。约 6 次运行出现 1 次，原因未查明，仅影响调试截图。 |
| **T10** | 功能 | 模式 2 下支持命令流 | 有提交路由时帧主列表自动退回直接录制（回放落后渲染线程最多两帧，而描述符集内容不按帧分版本，实测 06 约 10 帧后 GPU 挂起）。 |

## 二、已实现但有限制或未能在实际场景中验证

| 项目 | 限制 / 已做的验证 |
|------|------|
| 命令流模式下不绘制 ImGui | ImGui 直接往原生列表录制，绘制数据在下一帧失效，不能推迟回放；`HE_RHI_COMMAND_STREAM=1` 时跳过 ImGui 并警告一次。 |
| `ClearDepthStencil` | 唯一调用方是 05 路径追踪的粒子深度，需 T5 完成后才能运行。 |

| 瞬态纹理及其内存别名 | 样例中 RenderGraph 自建纹理数为 0。临时自检：生命周期 [1,2] 与 [3,4] 的纹理放在同一偏移，与二者都重叠的 [2,3] 单独放置；别名屏障 + `DiscardResource` 在调试层与 GPU 验证下 0 报错。 |
| 异步计算列表的队列交接 | 样例的异步 pass 数为 0。临时把 GPU_Cull 放到计算队列验证过：DEPTH_WRITE → COMMON、PIXEL\|NON_PIXEL → NON_PIXEL 的交接转换正确，调试层 0 报错。 |
| Profiler 在有异步 pass 时改在计算列表上重置查询池 | 样例中异步计算 pass 数为 0，该路径未被执行。 |
| 多线程录制（bundle 实现的二级命令列表） | 样例绘制数达不到 64 条的并行门槛；仅在临时降低门槛时验证过（03 / 06 画面与基线一致、调试层 0 报错）。 |

## 三、已决定不实施

| 功能 | 原因 |
|------|------|
| 轻量 Begin（`BeginLightweight`） | 默认实现即调用 `Begin()`。D3D12 的 Begin 只轮换本列表自己的帧槽位，没有 Vulkan 那样的全局帧计数推进与延迟销毁副作用，默认实现已正确。 |
| 渲染通道提示（`ID3D12GraphicsCommandList4::BeginRenderPass` 的加载 / 存储提示） | 只对分块渲染（TBDR）的移动端 GPU 有收益，桌面 GPU 几乎无差别。引擎在 pass 中间会为绘制补资源状态转换、切换只读深度视图（需要 `OMSetRenderTargets`），与原生渲染通道的限制冲突，改动面大且无法测出收益。 |

## 四、本轮已完成的工作与相关开关

| 功能 / 修复 | 说明 / 开关 |
|------|------|
| 深度模板清除、存储图像查询 | `ClearDepthStencil`、`SupportsStorageImage`（深度格式在 D3D12 下恒不支持 UAV） |
| 异步计算状态处理 | 计算列表过滤图形专用状态，图形队列先做交接转换、计算队列等待后执行 |
| 网格着色器 | 管线状态流创建网格 PSO，`DispatchMesh` 与 `DISPATCH_MESH` 命令签名；`*.mesh` / `*.task` 生成 DXIL（见 T3） |
| DGC 等价实现 | DRAW_INDEXED 命令签名 + 带计数缓冲的 `ExecuteIndirect`，缓冲按 GPU 地址登记反查 |
| PSO 创建限流 | `EnqueuePSOCreate` / `ProcessPSOCreateQueue` / 句柄版占位创建 |
| Agility SDK 1.620.1 | configure 时从 nuget.org 下载并校验 SHA256（`cmake/AgilitySDK.cmake`，`HUGENGINE_D3D12_AGILITY` 可关闭）；样例 exe 导出 `D3D12SDKVersion` / `D3D12SDKPath`，运行时放在 exe 旁的 `D3D12\` 子目录，**缺少该目录时建设备失败**（日志有明确提示） |
| 瞬态纹理内存别名 | RenderGraph 传入生命周期，生命周期不重叠的纹理共用内存 |
| 提交路由（模式 2） | `HE_RENDER_THREADING_MODE=2`：Submit / Present 交给 RHI 线程；命令列表按帧槽位各持原生列表，提交数据打包入队 |
| 命令流模式 | `HE_RHI_COMMAND_STREAM=1`：帧主列表录成数据流，提交时回放到影子列表（模式 2 下不开，见 T10） |
| WARP 适配器 | `HE_D3D12_WARP=1`：改用 WARP 做功能验证 |
| Lumen 统计确定性回读 | `LumenStatsReadback`；反馈槽位 kMaxFramesInFlight + 1（读数待 T2 复核） |
| 窗口缩放泄漏描述符集 | 缩放时不再重建天空盒（此前每次缩放泄漏一个 11 槽位的集） |
| 每帧刷日志 | 删除 `[CSMB]` / `[CSMP]`；粒子调试只打前几帧；`[TEX-BIG]` 与瞬态分配器降为 TRACE；DDGI 拟合只在参数变化时打印 |
| NaniteRaster 材质 bindless 数组 | binding 13/14 显式放到 `register(t0/s0, space2)`，修正读取未初始化根参数 |
| Nanite 按簇派发 | 软光栅三趟与网格硬光栅改为二维派发（宽 `kNaniteRasterDispatchWidth = 1024`） |
| 合批顶点偏移 | `MeshBatcher` 的间接命令与 DGC 序列 `vertexOffset` 改为 0（索引已是绝对索引） |
| T1 复测通过 | RTX 4060 Laptop 上依次运行 02 / 04 / 06 / 07（`HE_D3D12_DEBUG_LAYER=1` + `HE_D3D12_GPU_VALIDATION=1`）各 45 秒：无崩溃，`[D3D12 ERROR]` 0 条，GBV 报错 0 条。原崩溃在系统自带调试层，已由 Agility SDK 1.620.1 的调试层解决 |
| T3 验证通过 | RTX 4060 上 `nanite_mesh_test=1`：`网格管线创建成功 name=NaniteMeshTest MS=3432B`，日志无 `[D3D12 ERROR]`；再加 `nanite_soft_raster=1` + `nanite_hard_raster=1`，软/硬光栅四个计算 PSO 与 `NaniteHardRaster` 图形 PSO 均创建成功、无崩溃。**WARP 上不再崩溃**（`HE_D3D12_WARP=1` 下网格管线同样创建成功），原先的访问空指针问题已随二维派发与材质 bindless 落位修复消失 |
| T5 已实现 | 加速结构（BLAS/TLAS）、状态对象（DXIL 库 + 命中组 + 组句柄）、BuildRaytracingAccelerationStructure、DispatchRays、AS 型描述符写入全部实现；新增 D3D12RayTracing.h/.cpp。RTX 4060 上 05.Sponza-PathTracing（HE_D3D12_RT=1）稳定运行、调试层与 GPU 验证 0 报错、截图 978 KB，与 Vulkan 同帧落盘统计量一致。遗留：RT 管线的 FXAA 在 D3D12 下偏暗，已默认关闭（HE_PT_FXAA=1 可复查） |

### 常用环境变量

| 变量 | 作用 |
|------|------|
| `HE_RHI_BACKEND=d3d12` / `vulkan` | 选择后端 |
| `HE_D3D12_DEBUG_LAYER=1` | 打开 D3D12 调试层（错误以 `[D3D12 ERROR] id=…` 写入日志） |
| `HE_D3D12_GPU_VALIDATION=1` | 打开 GPU 验证（GBV） |
| `HE_D3D12_DRED=1` | 打开 DRED，设备移除时输出面包屑与页错误 |
| `HE_D3D12_WARP=1` | 使用 WARP 软件适配器 |
| `HE_CAPTURE_FRAME=N` | D3D12 下第 N 帧把后缓冲存为 `capture_frameN.png`（exe 所在目录） |
| `HE_RENDER_THREADING_MODE=0/1/2` | 单线程 / 游戏 + 渲染线程 / 再加 RHI 线程（提交路由） |
| `HE_RHI_COMMAND_STREAM=1` | 帧主列表使用命令流模式 |
| `HE_TRACE_PASSES=1` | 每个 RenderGraph pass 开始时打印 pass 名 |
