## 三、已决定不实施

| 功能 | 原因 |
|------|------|
| 轻量 Begin（`BeginLightweight`） | 默认实现即调用 `Begin()`。D3D12 的 Begin 只轮换本列表自己的帧槽位，没有 Vulkan 那样的全局帧计数推进与延迟销毁副作用，默认实现已正确。 |
| 渲染通道提示（`ID3D12GraphicsCommandList4::BeginRenderPass` 的加载 / 存储提示） | 只对分块渲染（TBDR）的移动端 GPU 有收益，桌面 GPU 几乎无差别。引擎在 pass 中间会为绘制补资源状态转换、切换只读深度视图（需要 `OMSetRenderTargets`），与原生渲染通道的限制冲突，改动面大且无法测出收益。 |

### 常用环境变量

| 变量 | 作用 |
|------|------|
| `HE_RHI_BACKEND=d3d12` / `vulkan` | 选择后端 |
| `HE_D3D12_DEBUG_LAYER=1` | 打开 D3D12 调试层（错误以 `[D3D12 ERROR] id=…` 写入日志） |
| `HE_D3D12_GPU_VALIDATION=1` | 打开 GPU 验证（GBV） |
| `HE_D3D12_DRED=1` | 打开 DRED，设备移除时输出面包屑与页错误 |
| `HE_D3D12_WARP=1` | 使用 WARP 软件适配器 |
| `HE_CAPTURE_FRAME=N` | D3D12 下第 N 帧把后缓冲存为 `capture_frameN.png`（exe 所在目录） |
| `HE_RENDER_THREADING_MODE=0/1/2` | 单线程 / 游戏 + 渲染线程 / 再加 RHI 线程（提交路由） |
| `HE_RHI_COMMAND_STREAM=1` | 帧主列表使用命令流模式 |
| `HE_TRACE_PASSES=1` | 每个 RenderGraph pass 开始时打印 pass 名 |
