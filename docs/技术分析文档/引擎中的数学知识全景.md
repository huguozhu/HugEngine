> **本文定位**：按"数学分支"梳理引擎里用到的数学知识，回答"除了球谐函数，还用了哪些重要的数学"。
> 与 [引擎中的数学武器库](引擎中的数学武器库.md) 互补：
> - 本文按**学科**纵向列清单（线性代数、几何、概率、积分、信号处理……），便于"查漏补缺"；
> - 《数学武器库》按**主线**横向串讲（渲染方程 → 采样 → 积分 → 重建），便于"理解为什么"。
>
> 每项都给出**引擎里的落点**（文件/系统），方便顺着清单读代码。
> 球谐函数已单独成文：[球谐函数（SH）理论与引擎实现](球谐函数（SH）理论与引擎实现.md)。

## 1. 线性代数与坐标空间

| 数学 | 用途 | 引擎落点 |
|---|---|---|
| 向量/矩阵/四元数（glm 封装） | 变换、旋转、法线矩阵 | `Engine/Core/Math/Math.h`（`float4x4`、`quat`、`float3x4`） |

## 15. 数值方法与实现细节

- **定点/量化**：深度键 24 位、Nanite 位置 16 位、法线八面体 10+10、SH 全精度字面量；
- **确定性**：固定顺序累加、CPU/GPU 逐位一致的 PCG（`LumenSH.h` 镜像）、白炉解析判据；
- **浮点边界**：`max(ε)` 防除零、`saturate`、`log2(max(lum,1e-5))`、`maxCoC` 限幅；
- **精度换带宽**：半精度/定点打包是显存与带宽优化的主要手段。

## 16. 按数学分支的总结

| 数学分支 | 引擎里的代表 |
|---|---|
| 线性代数 | 变换、四元数、坐标空间、法线矩阵 |
| 解析几何 | 视锥平面、AABB/球、射线、锥剔除 |
| 微积分/积分方程 | 渲染方程、蒙特卡洛、pdf、BRDF 积分 |
| 概率统计 | 重要性采样、reservoir、方差、MIS、RR |
| 数值分析 | 迭代求解、量化、滤波、降噪 |
| 信号处理 | mip/预过滤、蓝噪声、TAA、高斯/À-Trous |
| 几何处理 | meshlet、BVH、LOD 误差、SDF |
| 色彩科学 | ACES、sRGB、PQ、色度学、曝光 |
| 物理 | 刚体、碰撞、介质（Beer–Lambert）、光学（Fresnel/折射） |
| 离散数学 | 采样序列（Halton/Hammersley/Fibonacci）、哈希/PCG |
