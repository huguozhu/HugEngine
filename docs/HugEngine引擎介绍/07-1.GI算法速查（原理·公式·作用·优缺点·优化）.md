## 0. 速查

### 0.1 量纲与契约（GI 里最容易错的地方）

| 约定 | 内容 | 为什么 |
|---|---|---|
| **间接漫反射源** | 返回 $L_o=\mathrm{albedo}\times\dfrac{E}{\pi}$，即**已含**接收面 albedo 与 $1/\pi$ | 归一化加权平均 $\frac{\sum c_iw_i}{\sum w_i}$ 的前提是各源在估**同一个量**；量纲不一会让结果随 albedo 漂移 |
| **间接镜面源** | 返回**完整镜面辐射度**（含菲涅耳与环境 BRDF） | 同上。⚠ 目前只有 IBL 满足，SSR / RT 反射 / Lumen 都不满足 |
| **AO 源** | 返回**遮蔽因子**（0..1），不是能量 | 它只调制间接项，不是独立估计量 |
| **无效条目的表达** | `alpha < 0` 表示"本条无数据" | 合成端**分子分母都不计**；按 0 计入分母会无谓稀释同通道其它源 |
| **$\pi$ 的来历** | $\int_\Omega\cos\theta\,\mathrm d\omega=\pi$，故朗伯 BRDF 为 $f_r=\rho/\pi$ | 于是 $L_o=\int f_rL_i\cos\theta\,\mathrm d\omega=\rho\cdot\frac{E}{\pi}$；白炉下 $E/\pi=1$ |
| **深度约定** | zero-to-one（近 0 / 远 1），**不是** reverse-Z；Hi-Z 金字塔是 **min** 深度 | 判据方向写反会让射线"一路前进到退出"、永不到达命中判定 |
| **UV 与 NDC** | 负高度视口，故 $\mathrm{ndc}_y = 1 - 2v$ | ⚠ SSGI / SSAO / GTAO / RSM 多处漏了这次翻转 |

### 0.2 算法总览

| 算法 | 路径 | 通道 | 输出量纲 | 一句话原理 | 分辨率 |
|---|---|---|---|---|---|
| **IBL** | 光栅化（预烘焙） | 漫反射 + 镜面 | $E/\pi$ 与完整镜面 | 天空盒预积分成三张图，运行时查表 | 32² / 128²×5mip / 512² |
| **SSGI** | 屏幕空间 | 漫反射 | $E/\pi$ | 半球采样前帧 HDR，余弦加权平均 | 全 / 半 |
| **SSR** | 屏幕空间 | 镜面 | ⚠ 反照率近似 | Hi-Z 层次 march 找反射交点 | 全 / 半 |
| **SSAO** | 屏幕空间 | AO | 遮蔽因子 | 半球撒点判 0/1 遮挡 | 全 / 半 |
| **GTAO** | 屏幕空间 | AO | 遮蔽因子 | 方位角切片 + 地平线解析积分 | 同 SSAO（同 pass） |
| **RSM** | 光栅化（光源 POV） | 漫反射 | $E$，合成端补 albedo | 光源视角存 VPL，逐 VPL 求和 | 半 |
| **DDGI** | Compute（可选光追） | 漫反射 | $E$，补 albedo/π | 探针网格 + 二阶 SH + 时间混合 | 探针网格 |
| **RTGI** | 硬件光追 | 漫反射 | $E/\pi$ | 半球余弦采样，1 次反弹 | **1/4** |
| **RT 反射** | 硬件光追 | 镜面 | ⚠ 不含菲涅耳 | GGX 重要性采样 + 一次反射线 | 半 |
| **RTAO** | 硬件光追 | AO | 遮蔽因子 | 半球射线，TMax 取遮蔽半径 | 半 |
| **Lumen** | SDF 追踪 + 远场光追 | 漫反射 + 镜面 | $E/\pi$ | SDF + Surface Cache + Screen Probe + SH | 探针网格 |

### 0.3 选型建议（按场景）

| 场景 | 建议组合 | 理由 |
|---|---|---|
| 只有天空盒、无动态 GI 需求 | **IBL** | 最便宜、无噪、覆盖无限远 |
| 静态相机或静态场景 | IBL + **SSAO / GTAO** | 屏幕空间信息齐全，AO 提升接触感 |
| 需要多次弹射（颜色渗透） | IBL + **SSGI**（+ DDGI 兜底屏外） | SSGI 用前帧 HDR 做时域反馈，天然含多次弹射 |
| 大场景、屏外可见、低频够用 | IBL + **DDGI** | 世界空间，屏外可命中，时序稳定 |
| 有硬件光追、要几何精确 | IBL + **RTGI** + **RT 反射** + **RTAO** | 一次反弹精确 + 真实反射；注意四者成本叠加 |
| 追求软 GI（UE Lumen 级） | **Lumen**（+ DDGI 作 Radiance Cache） | 世界空间软 GI；成本最高，需按帧预算取舍 |
| 镜面细节但无光追 | IBL + **SSR** | 屏内可见几何的反射，屏外由 IBL 兜底 |

---


> **本部分的排序规则（两级键）**
>
> 1. **一级键 —— 通道类型**，与合成端三通道同序：**漫反射（diffuse）→ 镜面（specular）→ 环境光遮蔽（AO）**。
>    GI 源的唯一归属就是它往哪个通道输出，而合成端也是按这三个通道遍历层栈的 ⇒ 这样排最便于"我要改哪个通道"的检索。
> 2. **二级键 —— 同一类型内按"实现手段的成本与信息范围阶梯"由低到高**：
>    **预积分查表 → 屏幕空间 → 光源视角光栅 → 世界空间探针 → 硬件光追 → 混合**。
>    成本与信息范围同向递增，于是从前往后读就是"由便宜到贵、由近似到精确"。
> 3. **双通道算法按主通道归入**，并在标题与正文注明它同时提供另一通道的项：IBL 的辐照度归入 diffuse，
>    其镜面预滤波与 BRDF LUT 在同节内说明；Lumen 一份估计量同时喂两个通道，归入 diffuse 并注明镜面用法。

## 漫反射源（diffuse）

## 1. IBL —— 基于图像的光照

**原理**：把天空盒**预积分**成三张与视角无关的表 —— 辐照度立方图（漫反射的余弦卷积）、预滤波图（镜面，按粗糙度分 mip）、BRDF LUT（Split-Sum 的第二项）。运行时只做查表相乘，不发射任何射线。

**公式**：

$$E(N)=\int_\Omega L_i(\omega)\cos\theta\,\mathrm d\omega \qquad\Longrightarrow\qquad \text{stored as}\ \ \frac{E}{\pi}$$

$$L_{spec}\approx \underbrace{\mathrm{prefilter}(R,\ r)}_{V=N=R}\times\bigl(F_0\,A+B\bigr),\qquad A,B\ \text{from BRDF LUT at}\ (N\!\cdot\!V,\ r)$$

**作用**：环境光的**基准**，也是所有 GI 源失效时的兜底；引擎里唯一的"无限远"源。它还是**唯一乘 $k_D$ 的漫反射源**（其余四个漫反射源只乘 albedo）。

**优缺点**：

| 优点 | 缺点 |
|---|---|
| 运行时极便宜（查表）；无噪声；覆盖无限远 | 不响应局部动态物体；只在天空盒变化时重烘焙，且脏标记**只比指针**（改 intensity 不重烘焙） |
| 镜面已用 GGX 重要性采样（256 样本） | ⚠ **辐照度仍是均匀网格黎曼和**：白炉偏低约 1.85%；含太阳盘时漏亮斑（太阳盘只占半球约 0.137% 立体角，每 texel 期望仅约 5 个样本命中） |
| Split-Sum 把菲涅耳拆成 $F_0A+B$，对 Schlick 是**精确**的 | 近似发生在：$V=N=R$、$L_i$ 与 BRDF 的相关性被丢弃、粗糙度量化成 5 档 |

**优化**：辐照度改**余弦加权 / 环境亮度重要性采样 / SH-9**（三条在 07 里只给了名字，均未落地）；脏标记扩成"输入指纹"（指针 + intensity + 旋转 + 尺寸）；BRDF LUT 与天空盒解耦（它本就无关，不该随脏重算）；预滤波 mip 数与样本数按质量档权衡。

## 2. SSGI —— 屏幕空间全局光照

**原理**：对每个像素在法线半球撒样本，取**命中点的入射辐射度 $L_{in}$**（来自**上一帧 HDR** —— 既解决因果，又构成多次弹射的时域反馈），再做余弦加权平均。

**公式**：

$$\mathrm{out}=\frac{\sum_i L_{in,i}\cos\theta_i}{\sum_i \cos\theta_i}\ \xrightarrow{\ \text{uniform hemisphere}\ }\ \frac{E}{\pi}$$

比值估计量的关键性质：分母 $\sum\cos\theta$ 就是 $\int\cos\theta\,\mathrm d\omega=\pi$ 的蒙特卡洛估计，故**权重在分子分母抵消**，白炉下恒为 1。推导见 07 §2.3。

**作用**：漫反射通道的**中频**补充；引擎里唯一"用前帧 HDR 自己构成多次弹射"的屏幕空间源。

**优缺点**：

| 优点 | 缺点 |
|---|---|
| 无需光追、每帧实时；自带多次弹射反馈；与 SSR 共用降噪链与 Provider 抽象 | 屏外与被遮挡几何无信息；有噪声 |
| 估计量无经验增益、无需标定 | ⚠ 采样核**角向非均匀**（盒体积采样后归一化，体对角密度达 5.196 倍）⇒ 对非恒定环境有**方向性偏差**，而**白炉测不出** |
| — | ⚠ 核恒 32 而 `sampleCount` 可配 4~64（超 32 会越界读 UBO）；`radius` 无场景尺度自适应（Sponza 下亚像素）；参数 UBO 单份每帧 `Map+memcpy`；UV 与 NDC 漏 y 翻转 |

**优化**：改**真正的半球均匀采样**（或保留原分布但显式除 pdf）；`radius` 按场景尺度自适应（照 SSR 的 `autoScaleMarch`）；核大小与 `sampleCount` 对齐并加范围断言；参数 UBO 分帧槽；修 y 翻转（**修半径之前必须先修它**，否则会把方向错误放大）；`den == 0` 与天空像素返回 `alpha = -1`。

## 3. RSM —— 反射阴影贴图

**原理**：从**光源视角**把场景渲染一次，存下 VPL（虚拟点光源）的三个附件 —— 世界位置、编码法线、出射辐射度；间接光等于对所有 VPL 求和。它是"光源 POV 的一次反弹"，因此比常数量环境光更有方向性。

**公式**：

$$L_o=\sum_j \frac{\Phi_j}{\pi}\frac{\cos\theta_p\cos\theta_j}{r_j^{2}}\,V_j$$

⚠ 代码里 $V_j\equiv 1$（**没有可见性项**）。生成端 $L_v=\mathrm{albedo}\cdot \mathrm{lightColor}\cdot \mathrm{intensity}\cdot(N\!\cdot\!L)/\pi$，采样缩放 $\mathrm{scale}=A/\pi$（$A$ 为 VPL 采样面积）。

**作用**：漫反射通道；在 GI 层栈里提供"有方向性的间接光"，成本低于光追。

**优缺点**：

| 优点 | 缺点 |
|---|---|
| 便宜（一次光栅 + 半分辨率 VPL 求和）；有方向性；光源视锥按场景包围盒自适应 | ⚠ **完全没有可见性项**（不采阴影图、不做深度比较）⇒ 漏光没有任何兜底 |
| 与 DDGI 共用"世界空间 GI"的思路 | ⚠ 半分辨率 + 16 点 Poisson 盘 ⇒ VPL 密度受限；⚠ UV 查找漏 y 翻转（垂直镜像，现有的覆盖率与相关性判据都看不见） |
| — | ⚠ Forward 的 5×5 与 Deferred 的 16 点是**两套图案**（同配置下两条管线结果不同）；`d2` 下限是唯一没随场景尺度走的常数 |

**优化**：补可见性（深度比较或阴影图）；统一两条管线的采样图案；修 y 翻转；`d2` 下限改成相对场景尺度的量；Forward 侧 `RSMProvider` 补 `GetTimedPass()` 以便进耗时面板。

## 4. DDGI —— 动态漫反射全局光照

**原理**：在场景体积里布**探针网格**；每个探针沿固定方向集（Fibonacci）取入射辐射度，投影成**二阶 4 系数 SH**，再随时间混合；查询时三线性插值 + 施加 Lambert 卷积。

**公式**：

$$L_{lm}=\frac{4\pi}{N}\sum_i L_i\,Y_{lm}(\omega_i) \qquad\text{(projection, no cosine term)}$$

$$E(n)=\sum_l A_l L_{lm}Y_{lm}(n),\qquad A_0=\pi,\quad A_1=\frac{2\pi}{3}$$

量纲：查询返回**辐照度 $E$**，故合成端补 $\mathrm{albedo}/\pi$；RTGI 的 miss 回退处也乘一次 $1/\pi$（两处口径一致，07 §2.5 已核对到常量逐位相符）。

**作用**：漫反射通道的**低频、远距离** GI；世界空间 ⇒ 屏外也能命中；既给 RTGI 做 miss 回退，也给 Lumen 当 Radiance Cache。

**优缺点**：

| 优点 | 缺点 |
|---|---|
| 世界空间、屏外可用；时序稳定、每帧增量更新；可硬件光追 march 加速 | 低频；光照突变有**滞后**（时间混合的固有代价） |
| 与 Lumen 复用同一套探针与 SH 表示 | ⚠ **没有深度矩**（每探针只有 4 系数 SH）⇒ 可见性只靠"距离门限"近似，漏光较明显 |
| — | ⚠ 6 个绑定已死（`u_GBufferA/B`、`u_Depth`、`u_PointSampler`、`u_PrevHDR`、`u_RSMPositionMap` 全是"只声明"）；⚠ `NeedsRadianceHistory()` 的依据已过期 ⇒ 每帧白付一次 1/4 下采样；硬件光追 march 默认**全量**发射而只用其屏外部分 |

**优化**：实现或恢复**深度矩 + Chebyshev 可见性**（改善漏光）；清理死绑定与过期门控；轨迹 march 只对需要的探针发射；调 `blendAlpha` 与 `updateStride` 权衡滞后与稳定。

## 5. RTGI —— 硬件光线追踪 GI

**原理**：对 GBuffer 有效像素在法线半球**余弦采样 N 条射线**，做**一次反弹** —— 命中点由 ClosestHit 评估其出射辐射度；未命中按三分支处理。

**公式**：

$$L_o=\frac{1}{N}\sum_i \begin{cases} L_o^{\mathrm{hit}} & \mathrm{hit}\\ 1 & \mathrm{furnace}\\ \mathrm{DDGI}(p,\omega)\cdot\pi^{-1} & \mathrm{fallback}\\ 0 & \mathrm{otherwise}\end{cases}$$

四个分支依次是：命中（rchit 评估）、白炉、DDGI 不在漫反射层栈时的降级回退、以及"这条射线没有任何 RTGI 自己的信息"（此时不计入 `valid`）。命中点辐射度 $L_o^{\mathrm{hit}}=\frac{\mathrm{albedo}}{\pi}(E_{amb}+E_{dir})$，其中的 $1/\pi$ 已在 `RT_HitCommon` 内完成。

**作用**：漫反射通道的**中距离（5~30 m）精确**间接光；与 DDGI 分工（后者管远距离低频），两者在漫反射层栈里归一化加权。

**优缺点**：

| 优点 | 缺点 |
|---|---|
| 几何精确、含真实可见性；是少数能同时给出"屏外 + 精确"的漫反射源 | 需硬件光追与 TLAS；⚠ 1/4 分辨率且 SPP 被夹到 ≤8 ⇒ 噪点靠时域压制 |
| 降噪链完整（`Temporal → Denoise → Upscale`，四效果里与 RT 反射同级） | ⚠ 低分辨率派发**未换算 GBuffer 索引**（偏 `uv/4`）；`r.RT.GI*` 有 3 个空开关；`RT_GI.rmiss` 的天空色是**死代码**；miss 回退依赖 DDGI（DDGI 不在层栈时质量下降） |

**优化**：提高 SPP（先统一 C++ 与 shader 的夹取口径）并加大时域历史；修索引换算；清理空 CVar 与死代码；命中点可补 emissive 与 IBL 细节。

## 6. Lumen —— 虚拟化几何 GI

**原理**：用 **Mesh/Global SDF** 表达远处几何，用 **Surface Cache** 缓存世界空间辐照度，用 **Screen Probe** 布探针并沿 SDF 追踪，再做 SH 投影与空间/时域滤波得到逐像素辐照度；远场另用硬件光追并与 SDF 追踪逐光线对照混合。**Radiance Cache 由 DDGI 承担**（输入换成 Screen Probe 的输出）。

**公式**：

$$L_o=\frac{\mathrm{albedo}}{\pi}\,E(n),\qquad E(n)=\sum_l A_l L_{lm}Y_{lm}(n)\quad\text{(same SH evaluation as DDGI)}$$

远场混合权重：$w=\mathrm{smoothstep}(40,60,d)$，即阈值 50 m、重叠带 $[40,60]$。

**作用**：**唯一的世界空间源**，且**一份估计量同时喂漫反射与镜面** ⇒ 帧图必须按 Provider 遍历；它刻意**不声明相机屏幕覆盖判据**（屏外可命中，屏幕边缘不退化）。

**优缺点**：

| 优点 | 缺点 |
|---|---|
| 世界空间软 GI（屏外可见）；SDF + 卡片把远处几何抽象掉，成本与几何复杂度解耦；软硬件混合 | 成本最高（毫秒级）；⚠ 无 screen trace（全仓只有配置与分类代码，实现为零） |
| 与 DDGI 复用探针与 SH 表示 | ⚠ Surface Cache **单次捕获、无辐照度通道** ⇒ 没有多弹射反馈；⚠ Feedback 双缓冲曾被"临时诊断"关掉（已修，留 `HE_LUMEN_SINGLE_FEEDBACK` 退路） |
| — | ⚠ 镜面分支直接取那张漫反射输出 ⇒ 与 §0.1 的镜面约定不符；探针滤波与回读路径存在逐趟不确定性（见 07 与《08.Lumen实现分析》） |

**优化**：落地 **screen trace**（配置项已存在、实现为零）；给 Surface Cache 加辐照度通道做**多弹射反馈**；恢复双缓冲（已做）并改进回读路径；SDF 分辨率与层数、探针密度、远场阈值按帧预算调参。

## 镜面源（specular）

## 7. SSR —— 屏幕空间反射

**原理**：把深度缓冲当几何，在**屏幕空间**求反射射线与已渲染几何的交点。加速结构是 **Hi-Z 层次 march** —— 直接复用 GPU 剔除系统那张 8 级 min 深度金字塔，SSR 不额外建。

**公式**（屏幕段参数 $t$ 与射线参数 $\tau$ 的**透视校正**；不做校正时实测偏差可达命中容差的 100 倍以上）：

$$w(t)=\frac{w_0w_T}{(1-t)w_T+t w_0},\qquad \tau(t)=\frac{t\cdot \mathrm{worldLen}\cdot w_0}{(1-t)w_T+t w_0}$$

命中判据为 $\lvert rayZ-gZ\rvert<\mathrm{thickness}$；命中输出 $\mathrm{albedo}\cdot \mathrm{hitAlbedo}\cdot\lvert N\!\cdot\!R\rvert$，未命中返回 `alpha = -1`。

**作用**：镜面通道的**中频**；与 RT 反射在**同一镜面层栈**竞争（`RTCounterpartOf` 把两者登记为同一物理量的两份估计）。

**优缺点**：

| 优点 | 缺点 |
|---|---|
| 不需要硬件光追；每帧实时；半分辨率 + 空间降噪；march 参数按场景对角线自适应 | 只有**屏幕内可见**几何；**无厚度信息**（薄物体穿透或误命中，只能用 `thickness` 经验带代替）；单次反弹 |
| 与 SSGI 共用同一份降噪链实现 | ⚠ 命中点用 **base color 近似辐射度**、且**不含菲涅耳与环境 BRDF** ⇒ 与 IBL 在同一归一化通道里量纲不一致；反射强度会随接收面 albedo 变化；Forward 管线没有 SSR |

**优化**：命中点改取**前帧 HDR 的辐射度**并补 $F$ 与粗糙度权重（与 SSGI 对齐）；屏外回退 IBL（已有）+ `CameraCoverage` 边缘淡出；用背面深度做厚度启发；加时域重投影。

## 8. RT 反射 —— 硬件光线追踪反射

**原理**：从 GBuffer 出发，按**GGX 微表面法线重要性采样**得到反射方向，发射**一次**反射光线；粗糙度超过阈值时**根本不发射**，直接回退 IBL 预滤波。

**公式**：

$$R=\mathrm{reflect}(-V,H),\qquad H\sim \mathrm{GGX}(N,r);\qquad r>\mathrm{maxRoughness}\ \Longrightarrow\ \text{fallback to IBL}$$

命中返回命中点出射辐射度（`a` 存命中距离），未命中回退天空色并置 `a = -1`。

**作用**：镜面通道的**高频/中频**；能反射屏外几何，与 SSR 在同一层栈位竞争。

**优缺点**：

| 优点 | 缺点 |
|---|---|
| 几何正确、含可见性；屏外可命中 | 需硬件光追；⚠ `r.RT.Reflection.SPP` 是**空开关**（rgen 不读 `sampleCount`，每像素恒 1 条射线） |
| 降噪链与 RTGI 同级（`Temporal → Denoise → Upscale`） | ⚠ **不含菲涅耳与环境 BRDF**（rchit 与 `RT_HitCommon` 里 `fresnel`、`envBRDF`、`F0` 均零命中）⇒ 与 IBL 量纲不一致 |
| 高粗糙度直接回退 IBL（单条射线在高粗糙下无意义） | ⚠ 低分辨率派发未换算 GBuffer 索引；另有 4 个 `r.RT.*` CVar 无读取点 |

**优化**：接上 SPP（或明确采用"1 spp + 更强时域"的口径并去掉误导性 CVar）；补 $F$ 与 `envBRDF`，或与 IBL 统一约定；修索引换算；`maxRoughness` 与 IBL mip 之间做混合过渡。

## 环境光遮蔽源（AO）

## 9. SSAO / GTAO —— 屏幕空间环境光遮蔽

**原理**：AO 估计**半球可见性**。它在合成端**只乘间接项**（直接光与自发光不乘），所以不是独立估计量，可与任意漫反射源共存。两种模式互替：SSAO 半球撒点判 0/1 遮挡；GTAO 沿方位角切片搜**地平线仰角**再做解析积分。

**公式**：

$$\mathrm{Vis}(N)=\frac{1}{\pi}\int_\Omega V(\omega)\cos\theta\,\mathrm d\omega,\qquad ao=\Bigl(1-\frac{1}{N}\sum_i \mathrm{rangeCheck}_i\Bigr)^{\mathrm{intensity}}$$

GTAO 的解析积分（Jimenez 2016）：

$$\mathrm{IntegratedArc}(h_1,h_2,n)=\lvert h_1-h_2\rvert\cdot\bigl(h_{1n}+h_{2n}\bigr),\qquad h_n=\frac{-\cos(2h-n)+\cos n+2h\sin n}{4}$$

⚠ 其中 $h_1,h_2,n$ **必须是角**；当前代码喂进去的是**余弦**（`GTAO.frag.slang:84/103/123/127`）。

**作用**：AO 通道；增强接触阴影与缝隙暗部；与 RTAO 互替（同样由 `RTCounterpartOf` 登记）。

**优缺点**：

| 优点 | 缺点 |
|---|---|
| 最便宜的 GI 类效果；SSAO 与 GTAO 共用一个 pass 与 UBO 布局 | ⚠ **GTAO 把余弦当角喂**：该式在代码自身定义域内上界为 1.4161，故 `visibility ≥ 0.549`，**形式上无法产生强遮蔽** |
| 视距缩放（`radius * abs(viewZ) * 0.5`）让 AO 尺度与画面一致；GTAO 同采样数下更准、噪点更少 | ⚠ 4×4 噪声纹理被 `ClampToEdge` **钳成整屏同一 texel** ⇒ 旋转与抖动实际是常量 |
| — | ⚠ UBO 缺 `u_View`，**世界空间法线被当 view 空间用**；⚠ UV 与 NDC 漏 y 翻转；`SSAO_Blur` 自称 depth-aware，实为无权重 5×5 box 且**没有深度输入** |

**优化**：GTAO 先取 `acos` 成角、地平线取相对视线（照 Jimenez 2016 / XeGTAO 原文）；噪声采样器改 `Repeat`（或换成 hash 噪声）；补 `u_View` 并转换法线；修 y 翻转；GTAO 每像素 4 切片 × 2 侧 × 6 步 = 48 次深度采样，可按质量档降；`SSAO_Blur` 若要真正 depth-aware 需加深度权重。

## 10. RTAO —— 硬件光线追踪环境光遮蔽

**原理**：对 GBuffer 有效像素在法线半球做**余弦采样**，每个样本发一条射线，**命中即视为遮蔽**；`TMax` 取**遮蔽半径**（默认 2 m）⇒ 只统计近处几何，等价于"局部 AO"。

**公式**：

$$AO=1-\frac{1}{N}\sum_{i=1}^{N} h_i,\qquad h_i=1\ \text{if}\ T_{\min}\le t_i\le T_{\max}$$

其中 $t_i$ 是第 $i$ 条射线的命中距离。射线用 `ACCEPT_FIRST_HIT_AND_END_SEARCH` 与 `SKIP_CLOSEST_HIT_SHADER`：AnyHit 即终止、不跑 ClosestHit。

**作用**：AO 通道；因遮蔽体可在屏外，它不受"屏幕空间信息缺失"影响（但被着色像素仍须在屏内，故仍是 `IsCameraViewLimitedSource`）。

**优缺点**：

| 优点 | 缺点 |
|---|---|
| 屏外几何也能参与遮蔽，无屏幕空间伪影 | 需硬件光追；⚠ SPP **双夹**（C++ 夹 1..16、shader 再夹 ≤8）⇒ 设 12 与设 8 等价 |
| 射线只走遮蔽半径，成本可控；降噪链为 `RT_AO_Denoise → Upscale` | ⚠ 低分辨率派发未换算索引；⚠ **依赖 AnyHit 而 BLAS 几何硬编码 `VK_GEOMETRY_OPAQUE_BIT_KHR` 且全仓无 `FORCE_NON_OPAQUE`** ⇒ 按 Vulkan 规范 AnyHit 不会被调用 ⇒ 可能恒输出 1.0（静态结论，**待转储判定**） |

**优化**：统一 SPP 夹取；修索引换算；处理 OPAQUE 与 AnyHit 的语义（加 `RAY_FLAG_FORCE_NON_OPAQUE` 或去掉几何的 opaque 位）；**补 AO 判据** —— `Tools/gi/` 目前没有任何 AO 判据，这类"开关为真、pass 在跑、内容恒空"的失效会长期隐形。

## 11. 未实现的三项

| 算法 | 原理 | 公式 | 作用 | 优缺点 | 优化方向 |
|---|---|---|---|---|---|
| **Lightmap**（枚举占位，任务 31 已取消） | 离线把静态几何的间接光烘进纹理，运行时按第二套 UV 采样 | $L_o=\mathrm{albedo}\cdot M(uv_2)$ | 静态场景零运行时成本的高质量 GI | 优：质量与成本双赢；缺：**静态**、需要 UV2 与存储、动态物体不参与 | 压缩与流式加载；与动态 GI 的混合权重 |
| **VXGI**（`GIMode::VXGI` 仅占位） | 把场景体素化成 clipmap，沿锥追踪求锥内平均可见性与辐射度 | $L_o\approx\sum_k w_k V_k$ | 世界空间、任意粗糙度的 GI 与反射 | 优：世界空间、可多分辨率；缺：体素化成本与内存、漏光、锥追踪带宽 | 稀疏或各向异性体素；并入 Lumen 已有的 SDF 路径 |
