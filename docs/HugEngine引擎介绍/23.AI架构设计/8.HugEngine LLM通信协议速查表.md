# HugEngine LLM 通信协议速查表

> 定位：`6.HugEngine LLM与引擎通信协议.md` 的代码级速查——LLM 与引擎之间"说什么、怎么说、怎么执行"的完整契约。
> 适用：`07.AISamples` 的 `FeatureLLMScene`（经 GenerativeAssetFactory → PromptToScene）与 AIGC 场景生成共用的协议。
> 最后更新: 2026-09-21

---

## 一、协议本质

**LLM 不写 C++、不改内存，只输出结构化 JSON（场景规格），引擎用解释器把它翻译成 `World` 变更。**

- 上行（引擎 → LLM）：注入 **system prompt**（格式模板 + 组件词汇表 + 规则）——告诉 LLM"能造什么、怎么写"
- 下行（LLM → 引擎）：输出 **场景 JSON**——引擎按反射/硬编码映射解释执行
- 所有变更走 `he::Command`（可撤销/可审查）

## 二、上行协议（引擎 → LLM）

### 2.1 System Prompt 结构（`Engine/AI/PromptToScene.cpp` → `BuildSceneSystemPrompt`）

```
你是 3D 场景生成器。根据用户描述，生成一个 JSON 场景描述。
输出必须是合法 JSON，格式如下：
{ "entities": [ { "name":"...", "transform":{"position":[x,y,z],"scale":[sx,sy,sz]},
                  "components":[{"type":"...", ...字段}] } ] }

可用的组件类型与字段（只能使用这些）：
<BuildTypeSchema() 输出>

规则：
- 只使用上述组件类型和字段，不要发明新类型。
- position 单位米，color 是 [r,g,b] 0~1，intensity 是正数。
- 场景必须包含至少一个光源和一个地面。
- 只输出 JSON，不要输出任何解释文字。
```

### 2.2 组件词汇表（`Engine/AI/TypeSchema.cpp` → `BuildTypeSchema`）

```json
{
  "component_types": {
    "Cube":             {"fields": ["halfExtent", "baseColor", "metallic", "roughness"]},
    "Sphere":           {"fields": ["radius", "segmentCount", "ringCount", "baseColor", "metallic", "roughness"]},
    "DirectionalLight": {"fields": ["direction", "color", "intensity", "castShadow"]},
    "PointLight":       {"fields": ["color", "intensity", "range"]},
    "SpotLight":        {"fields": ["direction", "color", "intensity", "range", "innerConeAngle", "outerConeAngle", "castShadow"]},
    "RectLight":        {"fields": ["normal", "color", "intensity", "width", "height", "range", "softness", "castShadow"]},
    "Camera":           {"fields": ["fov", "nearPlane", "farPlane", "isMain"]},
    "Health":           {"fields": ["maxHealth", "currentHealth", "bInvincible"]},
    "Decal":            {"fields": ["decalTexture", "size", "opacity", "projectionDepth"]},
    "PhysicalSky":      {"fields": ["sunDirection", "turbidity", "intensity"]},
    "Animation":        {"fields": ["currentClip", "time", "speed", "playing"]},
    "RigidBody":        {"fields": ["shape", "radius", "halfExtent", "height", "mass", "friction", "restitution", "isDynamic", "enabled"]},
    "NavMesh":          {"fields": ["cellSize", "width", "height"]},
    "NavAgent":         {"fields": ["target", "speed"]}
  },
  "transform": {"fields": ["position [x,y,z] 米", "scale [x,y,z] 可选"]},
  "color_format": "[r,g,b] 0~1",
  "notes": "每个实体必须有 transform.position；场景至少一个光源和一个地面；isMain=true 的 Camera 是主相机"
}
```

### 2.3 强制 JSON 输出（`Engine/AI/DeepSeekClient.cpp` → `BuildRequestBody`）

```cpp
req["response_format"] = { {"type","json_object"} };   // OpenAI 兼容 API 层强制
req["stream"] = false;
req["temperature"] = 0.2;                              // 低温度：输出更稳定
```

## 三、下行协议（LLM → 引擎）

### 3.1 场景 JSON 格式

```json
{
  "entities": [
    {
      "name": "实体名（可选）",
      "transform": { "position": [x,y,z], "scale": [sx,sy,sz] },
      "components": [ { "type": "...", ...组件字段 } ]
    }
  ]
}
```

### 3.2 组件字段明细（`Engine/AI/SceneBuilder.cpp` 硬编码映射）

| type | 字段 | 类型/说明 |
|---|---|---|
| `Cube` | `halfExtent` | float，半边长（缺省 0.5） |
| | `baseColor` | [r,g,b] 或 [r,g,b,a]，0~1 |
| | `metallic` / `roughness` | float，0~1 |
| | `emissive` | [r,g,b]，可选 |
| `Sphere` | `radius` | float |
| | `segmentCount` / `ringCount` | uint（细分） |
| | `baseColor` / `metallic` / `roughness` / `emissive` | 同上 |
| `DirectionalLight` | `direction` | [x,y,z] 世界空间光线方向 |
| | `color` | [r,g,b] 0~1 |
| | `intensity` | float 正数 |
| | `castShadow` | bool，可选 |
| `PointLight` | `color` / `intensity` | 同上 |
| | `range` | float，影响范围（米） |
| `SpotLight` | `direction` | [x,y,z] 聚光锥轴方向（世界空间） |
| | `color` / `intensity` / `range` / `castShadow` | 同 `DirectionalLight` |
| | `innerConeAngle` / `outerConeAngle` | float，内/外锥角（弧度） |
| `RectLight` | `normal` | [x,y,z] 发光面朝向法线 |
| | `color` / `intensity` / `range` / `castShadow` | 同上 |
| | `width` / `height` | float，发光面尺寸（米） |
| | `softness` | float，软阴影系数 [0,1] |
| `Camera` | `fov` / `nearPlane` / `farPlane` | float，垂直视场角（度）/近远裁剪面 |
| | `isMain` | bool，是否主相机（缺省 true） |
| `Health` | `maxHealth` / `currentHealth` | float，最大/当前生命值 |
| | `bInvincible` | bool，是否无敌 |
| `Decal` | `decalTexture` | String，贴花纹理路径（空 = 纯色片） |
| | `size` | [x,y] 世界单位尺寸 |
| | `opacity` | float [0,1] 不透明度 |
| `PhysicalSky` | `sunDirection` | [x,y,z]，OnCreate 归一化 |
| | `turbidity` | float 大气浑浊度 |
| | `intensity` | float 天空亮度 |
| `Animation` | `currentClip` | 整数，当前播放的动画片段索引 |
| | `time` / `speed` | float，播放时间（秒）/速度倍率 |
| | `playing` | bool，是否播放 |
| `RigidBody` | `shape` | 整数形状枚举（0=球 1=盒…，见 `RigidBodyComponent`） |
| | `radius` / `halfExtent` / `height` | float，形状尺寸 |
| | `mass` / `friction` / `restitution` | float，质量/摩擦/弹性 |
| | `isDynamic` / `enabled` | bool |
| `NavMesh` | `cellSize` | float，每格尺寸（米） |
| | `width` / `height` | 整数，网格列数/行数（均 >0 时才 `Resize`） |
| `NavAgent` | `target` | [x,y,z] 寻路目标点（世界坐标） |
| | `speed` | float，移动速度（米/秒） |

> 注：`TypeSchema` 词表中 `Decal` 还列出 `projectionDepth`，但 `SceneBuilder` 当前只读取 `decalTexture` / `size` / `opacity`，未解析该字段；且 `size` 的读取未做「缺省检查」（`comp["size"]` 直接取值），LLM 省略该字段时不保证安全降级——与 §3.3 的容错描述存在出入。

### 3.3 解释执行（`SceneBuilder::BuildScene`）

```
对每个 entity：
  1. World::CreateEntity(name)
  2. AddComponent<TransformComponent> → position / scale
  3. 对每个 component：按 type 硬编码创建组件并赋字段（上表）
  4. SceneGraph::SetParent(根)
容错（LLM 不可靠的三层兜底）：
  - 非法 JSON → 整体失败，零实体
  - 字段类型不符（如 halfExtent 传数组）→ 安全降级默认值，不抛异常
  - 未知组件类型 → 跳过并告警（不影响其余实体）
```

## 四、调用链（`07.AISamples` → `FeatureLLMScene`）

```
用户 prompt（"一个黄昏下的中世纪村庄..."）
  → GenerativeAssetFactory::GenerateSceneJson（device = IAIDevice，无 RHI/设备时直接失败）
      → system prompt = BuildSceneSystemPrompt()   ← 上行协议
      → IAIDevice::Chat → RemoteBackend → DeepSeekClient（json_object 强制）
      → ExtractSceneJsonFromResponse（取 content）  ← 下行协议
  → GenerativeAssetFactory::GenerateScene → BuildScene（JSON → World）  ← 解释执行
  → ForwardPipeline 渲染
```

## 六、扩展规则（新增组件/字段时）

1. **加字段**（现有组件）：改 `TypeSchema.cpp` 词表 + `SceneBuilder.cpp` 字段读取（安全降级）
2. **加组件类型**：改词表 + `SceneBuilder.cpp` 加一个 `else if (type == ...)` 分支（用现有 `AddComponent<T>` + 字段赋值）
3. **泛型化目标**：迁移到 `ClassInfo::factory` 按名构造 + `PropertyInfo` 写字段后，词汇表由 `WorldModel::TypeSchema()` 反射自动生成，`SceneBuilder` 无需再改——见 `AI与反射功能配合分析.md` §五
