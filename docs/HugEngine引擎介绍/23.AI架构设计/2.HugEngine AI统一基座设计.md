# HugEngine AI 统一基座设计（方案 1 · 底座）

> 定位：与 RHI 平级的推理硬件抽象 + 反射驱动的世界模型 + 一等公民智能体，让神经渲染、智能体、AIGC 都建立在这一个基座上。
> 总纲见 `1.HugEngine AI一等公民架构设计.md`。

---

## 1. 目标与非目标

**目标**：新增 `Engine/AI` 模块，使推理成为与渲染平级的一等硬件抽象，AI 与渲染共享同一个反射类型化的 World。

**非目标**：
- 不做训练框架（只做推理 + 微调调用钩子，模型由外部工具链产出）。
- 不重新实现通用 ML 库（复用 ONNX Runtime、GGUF、Streamline、RTX Kit）。
- 不做 AI 状态的网络复制。
- 不在本分册覆盖 AIGC 内容生成（见 `4.HugEngine AIGC创作平台设计.md`）。

---

## 2. 实现原理：为什么"几乎免费"

本设计复用现有设施，改造重心是"在正确位置插入一层抽象"，而非新造代码：

| 现有设施 | 位置 | 用途 |
|---|---|---|
| 宏驱动反射：`ClassInfo`（含 `factory`）、`PropertyInfo`、`TypeRegistry` | `Engine/Reflect/Reflect/ReflectionAPI.h` | 世界模型内省、按名构造组件 |
| `ForEachProperty` / `GetMemberPtr` | 同上 | 观察/动作对属性的泛化读写 |
| ECS：`World::AddComponent<T>` / `ForEachEntity` / `ForEachComponent` | `Engine/Scene/Scene/World.h` | 世界模型数据源、动作执行目标 |
| `Component` 基类 + `HE_COMPONENT()` | `Engine/Scene/Scene/Component.h` | Agent 组件挂载 |
| `Command` / `CommandHistory` / `PropertyChangeCommand` | `Engine/Editor/Editor/Command.h` | AI 动作可撤销 |
| `rhi::DeviceCaps`（已声明 `supportsCooperativeVectors`/`supportsLinearAlgebra`） | `Engine/RHI/RHI/Types.h` | 设计上用于 GPU 推理能力探测；**当前 `he::ai` 未读取 `DeviceCaps`**，`GPUBackend` 走的是普通 compute 核（能力降级链未实现） |
| `rhi::IRHIDevice`（`CreateBuffer/CreateTexture`） | `Engine/RHI/RHI/RHI.h` | GPU 后端承载 + 零拷贝 |
| `JobSystem`（Taskflow） | `Engine/Core/Threading/JobSystem.h` | 异步推理调度（需补流式车道） |
| `render::IRenderSubsystem` | `Engine/Render/Subsystem/RenderSubsystem.h` | 神经渲染子系统复用模式 |

## 4. 接口设计

### 4.1 Runtime：推理硬件接口（IHI）

`IAIDevice` 是 `rhi::IRHIDevice` 的镜像，区别在于它抽象"模型执行"而非"图元绘制"。

```cpp
// Engine/AI/Runtime/AIDevice.h
namespace he::ai {

// AI 设备能力 —— AI 专属能力位（不含 rhi::DeviceCaps 副本）
struct AIDeviceCaps {
    bool supportsGPU       = false;   // GPUBackend 可用（张量 + compute 推理）
    bool supportsCPU       = false;   // ONNX Runtime / GGUF 可用
    bool supportsRemoteLLM = false;   // 远程大模型可用
    bool supportsNPU       = false;   // NPU 直通（预留）
    u32  maxModelSizeMB    = 0;       // 单模型内存上限
};

enum class AIModelFormat { ONNX, GGUF, SafeTensors, RTXNS_Slang };
enum class AIDataType    { FP32, FP16, BF16, FP8, INT8, INT4 };

struct AITensorDesc {
    u32        elementCount = 0;
    AIDataType dtype        = AIDataType::FP32;
    bool       bindlessVisible = true;    // 与渲染共享（零拷贝）
};

struct InferenceRequest {
    IAIModel*       model = nullptr;      // 编译后的模型句柄（预置核可空）
    // 计算核选择（二选一）：内置核名 / 运行时自定义 SPIR-V
    String          kernel;
    Span<const u32> customSpirv = {};
    u32             pushConstantSize = 0;
    std::vector<u8> pushConstants;
    std::vector<std::pair<String, String>> params;   // 内置核 KV 参数
    std::vector<IAITensor*> inputs;          // StorageBuffer 输入（binding 0..n-1）
    std::vector<IAITensor*> textureInputs;   // 纹理输入（CombinedImageSampler）
    std::vector<IAITensor*> outputs;         // StorageBuffer 输出（可写）
    u32                     batchSize = 1;
};

// 推理句柄 —— 阻塞等待 + 流式回调（LLM 必需）
class IAIInference {
public:
    virtual ~IAIInference() = default;
    virtual bool IsDone() const = 0;
    virtual void Wait() = 0;
    virtual void Cancel() = 0;
    virtual void SetStreamCallback(std::function<void(const String&)> cb) = 0;
};

// ★ 推理设备 —— 与 rhi::IRHIDevice 同构
class IAIDevice {
public:
    virtual ~IAIDevice() = default;
    virtual AIDeviceCaps GetCaps() const = 0;
    virtual Ref<IAIModel>  LoadModel(AIModelFormat, Span<const u8> weights, const String& path) = 0;
    virtual Ref<IAITensor> CreateTensor(const AITensorDesc&) = 0;
    virtual Ref<IAIInference> Submit(InferenceRequest&&) = 0;

    // ★ 与渲染零拷贝互操作（神经渲染的关键）
    virtual Ref<IAITensor> WrapRHITexture(rhi::IRHITexture*) = 0;  // 读渲染纹理（已实现）
    virtual Ref<IAITensor> WrapRHIBuffer(rhi::IRHIBuffer*)  = 0;   // 读 bindless 缓冲（当前为占位，返回 nullptr）
    virtual rhi::IRHIBuffer* ExportBuffer(IAITensor*)       = 0;   // 写回渲染缓冲（已实现）

    // --- LLM 便捷方法（委托 RemoteBackend）---
    virtual String Chat(const String& systemPrompt, const String& userPrompt) = 0;
    virtual void   ChatStream(const String& systemPrompt, const String& userPrompt,
                              std::function<void(const String&)> onToken) = 0;

    // --- 张量数据交换（CPU ↔ GPU）---
    virtual bool WriteTensor(IAITensor*, Span<const float> data, u32 offsetElems = 0) = 0;
    virtual bool ReadTensor (IAITensor*, Span<float> out,         u32 offsetElems = 0) = 0;
};
} // namespace he::ai
```

后端：`IAIBackend` 是 `IAIDevice` 的实现单元，`IAIDevice` 作为门面按模型格式 + 能力选择后端。工厂 `CreateAIDevice(InferenceScheduler*, rhi::IRHIDevice*)` 当前只注册 **RemoteBackend（需环境变量 `DEEPSEEK_API_KEY`）** 与 **GPUBackend（需传入 RHI 设备）**；`AIDeviceCaps::supportsGPU`/`supportsRemoteLLM` 即由这两者是否注册决定。

```cpp
// Engine/AI/Runtime/Backend/IAIBackend.h
class IAIBackend {
public:
    virtual ~IAIBackend() = default;
    virtual bool Supports(AIModelFormat fmt) const = 0;
    virtual Ref<IAIModel>  Load(AIModelFormat, Span<const u8> weights, const String& path) = 0;
    virtual Ref<IAITensor> Allocate(const AITensorDesc&) = 0;
    virtual Ref<IAIInference> Run(InferenceRequest&&) = 0;
};
```

**流式调度器**（`InferenceScheduler`，自建线程 + 优先级队列，不依赖 `JobSystem`）：
- **优先级车道**：`InferencePriority::Frame`（渲染耦合推理，如超分）> `Normal` > `Background`（LLM 智能体），互不阻塞；
- **流式回调**：经 `PostToMain()` 把 token 按序投递到主线程队列，主线程每帧 `DrainMainThread()` 执行，禁止在推理线程直接改 World。

### 4.2 WorldModel：反射驱动的世界模型

不新增任何场景数据结构。`WorldModel` 遍历 `World` + `TypeRegistry`，把反射属性自动序列化为 LLM 可读的语义快照。

```cpp
// Engine/AI/WorldModel/WorldModel.h
namespace he::ai {

struct ObservationFilter {
    float  radius = -1.0f;              // 以 center 为球心的空间范围（-1 = 全场景；当前暂未启用）
    float3 center = {0,0,0};            // 空间过滤中心（配合 radius 使用；当前暂未启用）
    u64    targetEntity = 0;            // 0 = 全部，否则仅该实体（已生效）
    std::vector<StringView> componentTypes; // 只导出这些组件类型（空 = 全部，已生效）
};

class WorldModel {
public:
    String Snapshot(World& world, const ObservationFilter& filter) const; // 语义快照（LLM 可读 JSON）
    String TypeSchema() const;  // 遍历 TypeRegistry，输出所有组件类型的可读写字段清单
};
}
```

新增反射注解（`Attribute.h` 的 `AttrKey` + `ReflectionMacros.h` 的 `HE_ATTR_*`，沿用 `prop.attributes.emplace_back(...)` 模式）：

| 注解 | 语义 |
|---|---|
| `HE_ATTR_AI_VISIBLE` | 该属性进入世界模型快照 |
| `HE_ATTR_AI_DESCRIPTION("...")` | 该属性/类型的自然语言说明（LLM 用） |
| `HE_ATTR_AI_WRITABLE` | 该属性允许 AI 写入（否则只读） |
| `HE_ATTR_AI_TOOL("name")` | 该方法暴露为 AI 可调用的工具 |

### 4.3 Agent：一等公民智能体

Agent 是挂载到 Entity 上的组件，与 `MeshComponent` 平级，享受同样的反射/序列化/编辑器内省。

```cpp
// Engine/AI/Agent/AgentComponent.h
namespace he::ai {

// 大脑策略抽象 —— LLM / RL / 行为树 可插拔
struct ActionPlan { TArray<Action> actions; };

class IBrain {
public:
    virtual ~IBrain() = default;
    // 依据「语义快照 JSON」+ 记忆，产出动作计划（注意：观察以 JSON 文本传入，而非 Observation 对象）
    virtual ActionPlan Decide(const String& observationJson, const MemoryComponent* memory) = 0;
};

// 一等公民组件（沿用 HE_COMPONENT 宏注册反射）
class AgentComponent : public he::Component {
    HE_COMPONENT()
public:
    String brainType     = "LLM";       // 策略类型（当前支持 LLM / Mock）
    String systemPrompt;                // 系统提示词
    f32    thinkInterval = 0.5f;        // 思考间隔（秒）
    bool   enabled       = true;
    f32    m_ThinkTimer  = 0.0f;        // 运行时状态（不注册为反射属性）
};
}

// 在 Engine/AI/Agent/AgentReflect.cpp 内注册（不放 SceneReflect.cpp，避免 Scene → AI 反向依赖）
// HE_BEGIN_REGISTER(he::ai::AgentComponent)
//     HE_REGISTER_PROPERTY(..., String, brainType)     HE_ATTR_CATEGORY("AI") HE_ATTR_AI_VISIBLE() HE_ATTR_AI_WRITABLE() HE_ATTR_AI_DESCRIPTION("大脑策略类型：LLM/Mock/RL")
//     HE_REGISTER_PROPERTY(..., String, systemPrompt)  HE_ATTR_CATEGORY("AI") HE_ATTR_AI_VISIBLE() HE_ATTR_AI_WRITABLE() HE_ATTR_AI_DESCRIPTION("系统提示词")
//     HE_REGISTER_PROPERTY(..., f32,    thinkInterval) HE_ATTR_CATEGORY("AI") HE_ATTR_AI_VISIBLE() HE_ATTR_AI_WRITABLE() HE_ATTR_AI_DESCRIPTION("思考间隔（秒）")
//     HE_REGISTER_PROPERTY(..., bool,   enabled)       HE_ATTR_CATEGORY("AI") HE_ATTR_AI_VISIBLE() HE_ATTR_AI_WRITABLE() HE_ATTR_AI_DESCRIPTION("是否启用")
// HE_END_REGISTER()
//
// MemoryComponent / GoalComponent 只注册类型，暂不注册属性：
// HE_BEGIN_REGISTER(he::ai::MemoryComponent)  HE_END_REGISTER()
// HE_BEGIN_REGISTER(he::ai::GoalComponent)    HE_END_REGISTER()
```

**动作 → 命令（可撤销）**：`Action` 内部映射到 `he::Command`，执行走 `he::CommandHistory`，AI 的每次写世界都可回滚。

```cpp
// Engine/AI/WorldModel/Action.h
struct Action {
    u64    targetEntity = 0;   // 目标实体（SpawnEntity 忽略）
    String op;         // 已支持："SpawnEntity" / "SetTransform" / "SetProperty" / "CastAbility"
    String argsJson;   // 参数（JSON 对象文本）
};
// 注意：签名带 SceneGraph（SpawnEntity 需装配层级）
std::unique_ptr<he::Command> CompileAction(he::World& world, he::SceneGraph& sg, const Action& a);
```

**工具调用**（`ToolUse`）：当前工具清单为 `SpawnEntity` / `SetTransform` / `SetProperty` 三项（`名字 + 说明`，以 JSON 注入 LLM 决策 prompt）。设计中的 `QueryVisible`/`PlayAnimation`/`CaptureScreenshot` 等尚未落地，工具参数 schema 亦未由反射自动生成。

### 4.4 Neural：神经渲染收编

Phase 5 的 `M73~M79` 重定义为 `he::ai` 运行时的消费者：
- 每个神经渲染特性实现为 `he::render::IRenderSubsystem`，内部通过 `IAIDevice` 做推理；
- NRC 用 `WrapRHITexture` 读渲染结果、`ExportBuffer` 写回辐射缓存；
- 神经材质权重以 bindless 缓冲存在，经 `WrapRHIBuffer` 零拷贝接入 `IAIDevice`。

**落地现状**：目前只有 `NeuralUpscaler` 一个子系统（`Engine/AI/Neural/`），且是"架构形态验证"实现（静态渐变输入纹理 + 每帧采样推理统计），真实超分（DLSS/FSR/XeSS）需待 Streamline SDK 接入；`NeuralRadianceCache`/`NeuralMaterial`/`RTXNeuralShader` 均未落地。零拷贝侧 `WrapRHITexture`/`ExportBuffer` 已实现，`WrapRHIBuffer` 仍为占位。

## 6. 错误处理与降级

- **后端不可用**：`LoadModel`/`CreateTensor`/`Submit` 返回 `nullptr` 并 `HE_CORE_WARN` 记录（当前未定义 `AIBackendUnavailable` 异常）。
- **设备能力不足**（无 CoopVec/linalg）：`GPUBackend` 退化为普通 compute dispatch，或转交 `CPUBackend`（**降级链为规划项，尚未实现**；`CPUBackend` 本身也未落地）。
- **远程 LLM 失败**：`Chat`/`ChatStream` 返回空串并记录错误（`DeepSeekClient::Chat` 内部 try/catch 兜底）；设计中的 `IAIInference::Failed` 状态与 `onError` 回调尚未实现，Agent 侧退避重试亦未实现。
- **动作非法**（实体已销毁、属性不存在）：`CompileAction` 返回 `nullptr`，不产生副作用。
- **AI 写世界可回滚**：所有写操作经 `CommandHistory`，异常时 `Undo`。
