本质：解渲染方程是一个无穷递归级数，全局光照决定计算到这个无穷递归级数到第几级
    局部光照：计算一次直接光照
    全局光照：计算反弹光照
使用GI算法主要使用4种核心方法：
    1. 缓存+复用：把diffuse、空间光预积分成纹理，通过查表代替重算
    2. 降维：把5D广场压缩：SH是角度降维，irradiance把方向积分去掉
    3. 采样代替积分：Monte Carlo采样逼近积分
    4. 复用屏幕信息：各类基于屏幕的GI：SSGI、SSR
所有GI都在回答3个问题：
    1. 缓存什么：辐照度CubeMap、SH系数探针、VPL列表、屏幕像素
    2. 怎么填充缓存：半球卷积、重要性采样、光追采样
    3. 怎么查询重建：直接采样、三线性插值、Ray Marching

DDGI = 缓存「空间各点的入射光方向分布（SH）」+ 用「沿 Fibonacci 球面方向取 Screen Probe / 光追 march / RSM / IBL 的辐射度」填充 + 用「三线性插值 + SH 评估（含 Lambert 卷积）」查询。
IBL(diffuse+specular) = 缓存「天空盒各方向的预积分光」+ 用「GGX 重要性采样卷积」填充 + 用「按 roughness 选 mip 采样」查询。
    近似发生在：𝑉=𝑁=𝑅, 𝐿𝑖与BRDF 的相关性被丢弃、粗糙度量化成5档
SSGI(diffuse)： 计算出射辐射度E/π ≈ ∑Lin*cosθi/(∑i*cosθi)
    问题：SSGI怎么判断采样半径
    
SSR(specular)： 在屏幕空间里求"反射射线与已渲染几何的交点"，再取该点的着色作为 Li 
RSM(diffuse)：从光源视角渲染一次场景，把每个 texel 视为一个小的虚拟点光源（VPL），存储其世界位置、法线、通量。主渲染时，在 light space 采样这些 VPL，累加它们对当前像素的单次反弹漫反射贡献。本质是「光栅化单次反弹」的近似。
DDGI(diffuse):物理量是探针位置处的入射辐照度,“动态漫反射全局光照”，是一种用探针网格 + 光线追踪 + 八面体深度/辐照度纹理来实现实时间接漫反射照明的技术。
