## 1. 全路径追踪的定义

### 1.1 进化路径

```
Level 1: 混合 RT (已规划)
  RT 替代各个光栅化效果（阴影/反射/AO/GI），但主可见性仍是光栅化 GBuffer

Level 2: PT 参考模式
  完整路径追踪替代 Lighting Pass，但 GBuffer 仍是光栅化的
  可作为"质量参考"或截图模式

Level 3: 全 PT 管线
  路径追踪替代 GBuffer Pass（主可见性），光栅化仅保留 UI/调试
  ReSTIR + SER + OMM + NRC 全栈优化
```

### 1.2 各阶段核心差异

| 维度 | Level 2 (PT 参考) | Level 3 (全 PT) |
|------|:---:|:---:|
| 主可见性生成 | 光栅化 GBuffer | Path Tracing RayGen |
| 直接光照 | ReSTIR DI (多光源重要性采样) | 同 Level 2 |
| 间接光照 | PT 1-2 bounce | PT 2-4 bounce + ReSTIR GI |
| 阴影 | 包含在 PT 中 | 包含在 PT 中 |
| 反射 | 包含在 PT 中 (BSDF 采样) | 同 Level 2 |
| AO | 包含在 PT 中 | 包含在 PT 中 |
| 降噪 | NRD (ReBLUR/ReLAX) | DLSS Ray Reconstruction (Transformer) |
| 超分 | DLSS/FSR/XeSS (可选) | DLSS/FSR/XeSS (默认, 低内部分辨率) |
| 帧生成 | DLSS-FG (可选) | DLSS-MFG (可选) |
| 硬件加速 | 基础 | SER + OMM + DMM |
| 神经加速 | STBN (时空蓝噪声) | NRC + STBN |

## 2. 整体架构

### 2.1 Level 3 全 PT 管线的 RenderGraph

```
全路径追踪管线的 BuildFrameGraph:

  GPU_Cull (AsyncCompute)
    ↓
  BLAS_Update (仅几何变更时)
    ↓
  TLAS_Build (每帧)
    ↓
  ReSTIR_InitialSampling (Compute Shader)
    对每个像素生成 M 个候选光源样本 → Reservoir
    ↓
  ReSTIR_TemporalReuse (Compute Shader)
    重投影历史 Reservoir → 合并
    ↓
  ReSTIR_SpatialReuse (Compute Shader)
    邻域像素共享 Reservoir 样本
    ↓
  PT_RayGen (RT Pass)  ← 主渲染 Pass
    └─ 发射主光线 → ClosestHit
       └─ 从 Reservoir 采样光源 → Shadow Ray (TraceRay)
       └─ BSDF 采样 → 间接光线 (TraceRay, 递归或迭代)
    └─ 输出: 噪声 HDR 颜色 + GBuffer (albedo/normal/depth/motionVec)
    ↓
  DLSS_RayReconstruction (或 NRD)
    从噪声 HDR + GBuffer 生成高质量降噪图像
    ↓
  ToneMap (HDR → LDR)
    ↓
  DLSS_SuperResolution (可选: 低内部分辨率 → 显示分辨率)
    ↓
  DLSS_FrameGeneration (可选: 从 LDR → 插值帧)
    ↓
  Present
```

### 2.2 与光栅化管线的共存

```
两个管线可共存于同一个引擎：

  if (r.Pipeline.Mode == 0) → DeferredPipeline（光栅化，现有）
  if (r.Pipeline.Mode == 1) → HybridRTPipeline（混合 RT）
  if (r.Pipeline.Mode == 2) → PathTracingPipeline（PT 参考）
  if (r.Pipeline.Mode == 3) → FullPTPipeline（全 PT）

  通过 ImGui 或 CVar 一键切换，底层共用 RTManager 的 AS 构建
```

## 3. 阶段 A: 路径追踪参考模式

### 3.1 目标

实现一个完整的路径追踪 RayGen Shader，理论上可以：
- 仅用 RayGen + ClosestHit + Miss 着色器渲染完整帧
- 支持任意 bounce 深度
- 支持直接光照 NEE (Next Event Estimation)
- 支持 MIS (Multiple Importance Sampling)
- 支持俄罗斯轮盘赌终止

### 3.2 核心着色器

```hlsl
// FullPT.rgen.slang — 全路径追踪 RayGen

struct PTPushConstant {
    float4x4 invViewProj;
    float3   cameraPos;
    uint     maxBounces;       // 最大弹射次数 (4-8)
    uint     sampleCount;      // 每像素 SPP
    uint     frameIndex;
    float    skyIntensity;
    uint     flags;            // bit0=MIS, bit1=NEE, bit2=RussianRoulette
};

[[vk::binding(0, 0)]] RaytracingAccelerationStructure g_TLAS;
[[vk::binding(1, 0)]] RWTexture2D<float4> g_Output;

// 场景数据（如果 SSBO 已修复）
[[vk::binding(2, 0)]] StructuredBuffer<GPUObjectData> g_Objects;
[[vk::binding(3, 0)]] StructuredBuffer<GPULight> g_Lights;
[[vk::binding(4, 0)]] uint g_LightCount;

// 天空环境光
[[vk::binding(5, 0)]] TextureCube<float4> g_SkyEnv;
[[vk::binding(6, 0)]] SamplerState g_Sampler;

struct PathPayload {
    float3 worldPos;
    float3 normal;
    float3 albedo;
    float  metallic;
    float  roughness;
    float  emissiveR, emissiveG, emissiveB;  // 命中点自发光
    uint   materialID;
    float  hitT;
    uint   instanceID;
};

[shader("raygeneration")]
void main() {
    uint2 idx = DispatchRaysIndex().xy;
    uint2 dim = DispatchRaysDimensions().xy;
    
    float3 radiance = float3(0, 0, 0);
    float3 throughput = float3(1, 1, 1);
    
    // 初始光线
    float2 jitter = BlueNoiseSample(idx, g_PC.frameIndex);
    float2 uv = (float2(idx) + jitter) / float2(dim);
    RayDesc ray = GenerateCameraRay(uv, g_PC.invViewProj, g_PC.cameraPos);
    
    for (uint bounce = 0; bounce < g_PC.maxBounces; bounce++) {
        PathPayload payload;
        payload.hitT = -1;
        payload.emissiveR = 0;
        payload.emissiveG = 0;
        payload.emissiveB = 0;
        
        TraceRay(g_TLAS, RAY_FLAG_NONE, 0xFF, 0, 0, 0, ray, payload);
        
        if (payload.hitT < 0) {
            // Miss: 采样天空/环境光 → 终止
            radiance += throughput * SampleSky(ray.Direction);
            break;
        }
        
        // 累积自发光
        radiance += throughput * float3(payload.emissiveR, payload.emissiveG, payload.emissiveB);
        
        // 读取材质
        MaterialData mat = MaterialFromPayload(payload);
        float3 N = payload.normal;
        float3 V = -ray.Direction;
        
        // NEE: 直接光照采样
        if (g_PC.flags & FLAG_NEE) {
            float3 directLight = SampleDirectLight_MIS(
                payload.worldPos, N, V, mat,
                g_Lights, g_LightCount,
                g_TLAS,  // 用于 shadow ray
                g_PC.frameIndex, idx, bounce
            );
            radiance += throughput * directLight;
        }
        
        // 俄罗斯轮盘赌终止
        if (g_PC.flags & FLAG_RUSSIAN_ROULETTE) {
            float survivalProb = min(max(throughput.x, max(throughput.y, throughput.z)), 1.0);
            if (bounce > 3 && BlueNoiseRandom(idx, g_PC.frameIndex, bounce) > survivalProb)
                break;
            throughput /= survivalProb;
        }
        
        // BSDF 采样 → 下一根光线
        float3 wi;
        float pdf;
        float3 bsdf = SampleBSDF(N, V, mat, wi, pdf);
        throughput *= bsdf / pdf;
        
        ray.Origin = payload.worldPos + N * 0.001;
        ray.Direction = wi;
        ray.TMin = 0.01;
        ray.TMax = 10000.0;
    }
    
    g_Output[idx] = float4(radiance, 1.0);
}
```

### 3.3 ClosestHit 着色器

```hlsl
// FullPT.rchit.slang — 路径追踪 ClosestHit

[shader("closesthit")]
void main(inout PathPayload payload) {
    uint instanceID = InstanceID();
    uint primitiveID = PrimitiveIndex();
    float2 barycentrics = HitTriangleBarycentrics();
    
    // 读取物体数据
    GPUObjectData objData = g_Objects[instanceID];
    
    // 读取材质
    MaterialData mat = LoadMaterial(objData.materialID);
    
    // 插值顶点属性 (需要 SSBO 或 position_fetch)
    float3 worldPos = WorldRayOrigin() + WorldRayDirection() * RayTCurrent();
    float3 N = HitTriangleVertexNormal(0) * barycentrics.x
             + HitTriangleVertexNormal(1) * barycentrics.y  
             + HitTriangleVertexNormal(2) * barycentrics.z;
    
    // 法线变换到世界空间
    N = normalize(mul(float4(N, 0), objData.worldMatrix).xyz);
    
    // 填充 payload
    payload.worldPos = worldPos;
    payload.normal = N;
    payload.albedo = mat.baseColor;
    payload.metallic = mat.metallic;
    payload.roughness = mat.roughness;
    payload.emissiveR = mat.emissive.x;
    payload.emissiveG = mat.emissive.y;
    payload.emissiveB = mat.emissive.z;
    payload.materialID = objData.materialID;
    payload.hitT = RayTCurrent();
    payload.instanceID = instanceID;
}
```

### 3.4 关键算法: NEE + MIS

```hlsl
// 直接光照采样 (Next Event Estimation + MIS)
float3 SampleDirectLight_MIS(
    float3 pos, float3 N, float3 V, MaterialData mat,
    StructuredBuffer<GPULight> lights, uint lightCount,
    RaytracingAccelerationStructure tlas,
    uint frameIdx, uint2 pixelIdx, uint bounce)
{
    float3 directLight = float3(0, 0, 0);
    
    for (uint li = 0; li < lightCount; li++) {
        GPULight light = lights[li];
        
        // --- 光源采样 (Light Sampling) ---
        float3 lightPos; float lightPdf;
        SampleLightPosition(light, pos, N, lightPos, lightPdf,
                            frameIdx, pixelIdx, bounce, li);
        float3 L = normalize(lightPos - pos);
        float dist = length(lightPos - pos);
        
        // BRDF 评估
        float3 brdf = EvaluateBRDF(mat, N, V, L);
        float brdfPdf = GGX_Pdf(V, N, L, mat.roughness);
        
        // Shadow Ray
        RayDesc shadowRay;
        shadowRay.Origin = pos + N * 0.001;
        shadowRay.Direction = L;
        shadowRay.TMin = 0.01;
        shadowRay.TMax = dist - 0.01;
        
        ShadowPayload spayload;
        spayload.blocked = false;
        TraceRay(tlas, 
            RAY_FLAG_ACCEPT_FIRST_HIT_AND_END_SEARCH |
            RAY_FLAG_SKIP_CLOSEST_HIT_SHADER,
            0xFF, 0, 0, 0, shadowRay, spayload);
        
        if (spayload.blocked) continue;  // 被遮挡
        
        // Power Heuristic MIS weight
        float misWeight = PowerHeuristic(lightPdf, brdfPdf);
        
        // 辐射度计算
        float3 Li = light.color * light.intensity / (dist * dist);
        directLight += brdf * Li * misWeight / lightPdf;
        
        // --- BRDF 采样 (BSDF Importance Sampling) ---
        // 如果光源在 BRDF 采样的方向附近，也给 MIS 权重
        // ... (MIS 第二部分)
    }
    
    return directLight;
}
```

## 4. 阶段 B: ReSTIR 时空重采样

### 4.1 算法概述

ReSTIR (Reservoir-based Spatio-Temporal Importance Resampling) 是 RTXDI SDK 的核心算法。它将直接光照采样问题转化为 WRS (Weighted Reservoir Sampling) 问题。

```
核心思想: 每个像素维护一个 Reservoir（样本池）
  Reservoir = { selectedLight, weightSum, M (可见样本数), W (权重和) }

每帧三个 Pass:
  1. Initial Sampling: 每像素随机采样 M 个光源候选 → 评估 → 存入 Reservoir
  2. Temporal Reuse: 从上一帧重投影位置读取 Reservoir → 合并
  3. Spatial Reuse: 从邻域像素读取 Reservoir → 合并

最终: 从 Reservoir 中采样 1 个光源 → Shadow Ray → 着色
```

### 4.2 着色器实现

#### Pass 1: Initial Sampling

```hlsl
// ReSTIR_Init.comp.slang — 初始采样 + Reservoir 构建

struct Reservoir {
    uint   lightIndex;         // 选中的光源索引
    float  weightSum;          // 权重和
    uint   M;                  // 累计样本数
    float  W;                  // 选中样本的权重
    float3 lightPos;           // 采样点的世界位置（阴影光线终点）
};

// 输入: GBuffer (worldPos, normal, roughness, metallic, albedo)
// 输出: InitialReservoir (RWStructuredBuffer)
// 备选: 输出到 RT 纹理 (float4×2)

[numthreads(8, 8, 1)]
void main(uint3 idx : SV_DispatchThreadID) {
    // 读取 GBuffer
    float3 worldPos = g_WorldPos[idx.xy];
    float3 N = g_Normal[idx.xy];
    float roughness = g_Roughness[idx.xy];
    float3 V = normalize(g_CameraPos - worldPos);
    MaterialData mat = LoadMaterial(g_MaterialID[idx.xy]);
    
    // 初始化 Reservoir
    Reservoir reservoir;
    reservoir.lightIndex = 0;
    reservoir.weightSum = 0;
    reservoir.M = 0;
    reservoir.W = 0;
    reservoir.lightPos = float3(0, 0, 0);
    
    // 候选样本数 (通常 4-32)
    uint M = g_CandidateSamples;
    
    for (uint i = 0; i < M; i++) {
        // 随机选择一个光源
        uint li = RandomInt(idx, g_FrameIndex, i) % g_LightCount;
        GPULight light = g_Lights[li];
        
        // 在光源上随机采样一个点
        float3 lightPos;
        float lightPdf;
        SampleLightPosition(light, worldPos, N, lightPos, lightPdf,
                           idx, g_FrameIndex, i);
        
        float3 L = normalize(lightPos - worldPos);
        float dist = length(lightPos - worldPos);
        
        // BRDF 评估
        float3 brdf = EvaluateBRDF(mat, N, V, L);
        float p_hat = luminance(brdf * light.color * light.intensity / (dist * dist)) / lightPdf;
        
        // WRS 更新
        reservoir.weightSum += p_hat;
        reservoir.M++;
        
        // 以概率 p_hat / weightSum 替换当前选中样本
        if (RandomFloat(idx, g_FrameIndex, i) * reservoir.weightSum < p_hat) {
            reservoir.lightIndex = li;
            reservoir.W = p_hat;
            reservoir.lightPos = lightPos;
        }
    }
    
    g_InitialReservoir[idx.xy] = reservoir;
}
```

#### Pass 2: Temporal Reuse

```hlsl
// ReSTIR_Temporal.comp.slang — 时域重采样

[numthreads(8, 8, 1)]
void main(uint3 idx : SV_DispatchThreadID) {
    Reservoir current = g_InitialReservoir[idx.xy];
    
    // 读取 Motion Vector
    float2 mv = g_MotionVector[idx.xy];
    float2 historyUV = (float2(idx.xy) - mv) / float2(g_Width, g_Height);
    int2 historyIdx = int2(historyUV * float2(g_Width, g_Height));
    
    // 边界检查
    if (historyIdx.x < 0 || historyIdx.x >= g_Width ||
        historyIdx.y < 0 || historyIdx.y >= g_Height) {
        g_TemporalReservoir[idx.xy] = current;
        return;
    }
    
    // 时域验证
    float3 historyPos = g_HistoryWorldPos[historyIdx];
    float3 historyN = g_HistoryNormal[historyIdx];
    if (distance(g_WorldPos[idx.xy], historyPos) > 0.1 ||
        dot(g_Normal[idx.xy], historyN) < 0.9) {
        g_TemporalReservoir[idx.xy] = current;
        return;
    }
    
    // 合并两个 Reservoir
    Reservoir history = g_TemporalReservoir_History[historyIdx];
    
    // 目标函数评估: 对当前世界位置评估历史光源
    float p_hat_current = EvaluateLightTarget(
        g_WorldPos[idx.xy], g_Normal[idx.xy], g_Roughness[idx.xy],
        g_Lights[current.lightIndex], current.lightPos);
    current.W *= p_hat_current;  // 修正当前 Reservoir 的目标函数
    
    float p_hat_history = EvaluateLightTarget(
        g_WorldPos[idx.xy], g_Normal[idx.xy], g_Roughness[idx.xy],
        g_Lights[history.lightIndex], history.lightPos);
    history.W *= p_hat_history;  // 修正历史 Reservoir 的目标函数
    
    // WRS 合并
    g_TemporalReservoir[idx.xy] = CombineReservoirs(current, history);
}
```

#### Pass 3: Spatial Reuse

```hlsl
// ReSTIR_Spatial.comp.slang — 空间重采样

[numthreads(8, 8, 1)]
void main(uint3 idx : SV_DispatchThreadID) {
    Reservoir center = g_TemporalReservoir[idx.xy];
    float3 centerPos = g_WorldPos[idx.xy];
    float3 centerN = g_Normal[idx.xy];
    
    // 空间采样半径 (2-5 像素)
    const uint radius = 3;
    const uint sampleCount = 5;
    
    for (uint i = 0; i < sampleCount; i++) {
        // 在邻域中随机采样
        int2 offset = int2(
            RandomInt(idx, g_FrameIndex + 100, i * 2) % (radius * 2 + 1) - radius,
            RandomInt(idx, g_FrameIndex + 200, i * 2 + 1) % (radius * 2 + 1) - radius
        );
        int2 neighborIdx = int2(idx.xy) + offset;
        
        // 边界检查
        if (neighborIdx.x < 0 || neighborIdx.x >= g_Width ||
            neighborIdx.y < 0 || neighborIdx.y >= g_Height)
            continue;
        
        Reservoir neighbor = g_TemporalReservoir[neighborIdx];
        float3 neighborPos = g_WorldPos[neighborIdx];
        float3 neighborN = g_Normal[neighborIdx];
        
        // 几何验证（拒绝不相似的邻域）
        if (distance(centerPos, neighborPos) > 0.1 ||
            dot(centerN, neighborN) < 0.9)
            continue;
        
        // 重新评估邻域 Reservoir 对当前像素的目标函数
        float p_hat = EvaluateLightTarget(
            centerPos, centerN, g_Roughness[idx.xy],
            g_Lights[neighbor.lightIndex], neighbor.lightPos);
        neighbor.W *= p_hat;
        
        // WRS 合并
        center = CombineReservoirs(center, neighbor);
    }
    
    g_FinalReservoir[idx.xy] = center;
}
```

#### Pass 4: Final Shade

```hlsl
// ReSTIR_Shade.comp.slang — 最终着色

[numthreads(8, 8, 1)]
void main(uint3 idx : SV_DispatchThreadID) {
    Reservoir reservoir = g_FinalReservoir[idx.xy];
    
    if (reservoir.M == 0) {
        g_DirectLight[idx.xy] = float4(0, 0, 0, 0);
        return;
    }
    
    GPULight light = g_Lights[reservoir.lightIndex];
    float3 worldPos = g_WorldPos[idx.xy];
    float3 N = g_Normal[idx.xy];
    float3 V = normalize(g_CameraPos - worldPos);
    MaterialData mat = LoadMaterial(g_MaterialID[idx.xy]);
    
    float3 L = normalize(reservoir.lightPos - worldPos);
    float dist = length(reservoir.lightPos - worldPos);
    
    // Shadow Ray
    RayDesc shadowRay;
    shadowRay.Origin = worldPos + N * 0.001;
    shadowRay.Direction = L;
    shadowRay.TMin = 0.01;
    shadowRay.TMax = dist - 0.01;
    
    ShadowPayload spayload;
    spayload.blocked = false;
    TraceRay(g_TLAS,
        RAY_FLAG_ACCEPT_FIRST_HIT_AND_END_SEARCH |
        RAY_FLAG_SKIP_CLOSEST_HIT_SHADER,
        0xFF, 0, 0, 0, shadowRay, spayload);
    
    if (spayload.blocked) {
        g_DirectLight[idx.xy] = float4(0, 0, 0, 0);
        return;
    }
    
    // 着色
    float3 brdf = EvaluateBRDF(mat, N, V, L);
    float3 Li = light.color * light.intensity / (dist * dist);
    
    // 无偏估计
    float3 result = brdf * Li * reservoir.W / (reservoir.weightSum * reservoir.M);
    
    g_DirectLight[idx.xy] = float4(result, 1.0);
}
```

## 5. 阶段 C: NRD 降噪器集成

### 5.1 NRD 集成架构

```
NRD (NVIDIA Real-time Denoisers) 提供三个降噪器:

  ReBLUR Diffuse   → PT GI (间接漫反射降噪)
  ReBLUR Specular  → PT Reflection (间接镜面降噪)
  SIGMA            → RT Shadow (阴影降噪)
  ReLAX            → ReSTIR DI (时空重采样信号降噪)
```

### 5.2 集成步骤

```
1. 下载/编译 NRD 库 → 链接到 HugEngine
   (https://github.com/NVIDIAGameWorks/RayTracingDenoiser)

2. 创建 Vulkan NRD 上下文
   - 初始化 nrd::Instance
   - 配置: CommonSettings (分辨率, 帧索引, 时间)
   - 配置: ReBLUR/ReLAX/SIGMA 各自的 Settings

3. 每个 RT Pass 后插入 NRD 降噪 Pass:
   
   RT_Reflection (噪声) → ReBLUR Specular Denoise → 降噪反射
   RT_GI (噪声)         → ReBLUR Diffuse Denoise  → 降噪 GI
   ReSTIR DI 输出       → ReLAX Denoise            → 降噪直接光照
   RT_Shadow (噪声)     → SIGMA Denoise            → 降噪阴影

4. NRD 输入: 
   - IN_DIFF_RADIANCE_HITDIST (颜色 + 命中距离)
   - IN_NORMAL_ROUGHNESS (GBuffer normal + roughness)
   - IN_VIEWZ (线性深度)
   - IN_MV (motion vector, 用于时域累积)

5. NRD 输出:
   - 降噪后纹理 → 直接输入到 Lighting/ToneMap
```

### 5.3 自研降噪方案 (NRD 不可用时的回退)

```hlsl
// SVGF_Atrous.comp.slang — A-Trous 小波滤波

[numthreads(8, 8, 1)]
void main(uint3 idx : SV_DispatchThreadID) {
    float3 centerColor = g_Input[idx.xy].rgb;
    float centerDepth = g_Depth[idx.xy];
    float3 centerN = g_Normal[idx.xy];
    
    const float sigmaColor = 0.5;
    const float sigmaDepth = 0.02;
    const float sigmaNormal = 0.1;
    
    // 5×5 A-Trous 滤波
    float3 sum = float3(0, 0, 0);
    float totalWeight = 0;
    
    const int kernel[25][2] = { /* 5×5 offset pattern */ };
    const float stepSize = pow(2.0, g_FilterIteration); // 每轮步长翻倍
    
    for (uint i = 0; i < 25; i++) {
        int2 sampleIdx = int2(idx.xy) + int2(kernel[i][0], kernel[i][1]) * int(stepSize);
        
        // 边界检查
        if (sampleIdx.x < 0 || sampleIdx.x >= g_Width ||
            sampleIdx.y < 0 || sampleIdx.y >= g_Height)
            continue;
        
        float3 sampleColor = g_Input[sampleIdx].rgb;
        float sampleDepth = g_Depth[sampleIdx];
        float3 sampleN = g_Normal[sampleIdx];
        
        // 边缘感知权重
        float wColor = exp(-length(sampleColor - centerColor) / sigmaColor);
        float wDepth = exp(-abs(sampleDepth - centerDepth) / sigmaDepth);
        float wNormal = pow(max(0.0, dot(sampleN, centerN)), 128.0);
        
        float w = wColor * wDepth * wNormal;
        sum += sampleColor * w;
        totalWeight += w;
    }
    
    g_Output[idx.xy] = float4(sum / max(totalWeight, 0.001), 1.0);
}
```

## 6. 阶段 D: ReSTIR GI + ReSTIR PT

### 6.1 ReSTIR GI 算法

将 ReSTIR 的 Reservoir 概念扩展到间接光照：

```
每像素 Reservoir 存储:
  - 间接光照光线 (方向 + 反弹次数)
  - 命中点的辐射度 (从 ClosestHit 返回)
  - 目标函数 (BSDF 权重)

每帧 Pass:
  1. Initial Sampling: 每像素发射 1-2 根间接光线 → 命中点 → Reservoir
  2. Temporal Reuse: 时域重投影 → 合并历史 Reservoir
  3. Spatial Reuse: 邻域空间重采样
  4. Final Shade: Reservoir 输出间接光照

与 ReSTIR DI 的区别:
  - DI: 采样光源（有限集合）
  - GI: 采样光线方向（无限连续域）→ 更难的采样问题
  - GI 需要 ClosestHit (读取命中点材质) 而 DI 只需要 shadow ray (任意命中)
```

### 6.2 ReSTIR PT (GRIS)

GRIS (Generalized Resampled Importance Sampling) 将 ReSTIR 扩展到完整路径追踪：

```
核心概念: 每个像素的 Reservoir 存储完整路径（而非单个 bounce）

Reservoir 内容:
  - 路径: [光线0, 命中0, 光线1, 命中1, 光线2, 命中2, ...]
  - 路径辐射度贡献
  - 目标函数值

优点:
  - 多个 bounce 的样本复用
  - 大光源/环境光采样质量大幅提升
  - 适用于焦散等困难光照场景

挑战:
  - 路径状态存储量大（每条路径 × N bounce 的材质数据）
  - 时域重投影验证更复杂（路径几何一致性）
```

## 7. 阶段 E: 硬件加速优化

### 7.1 SER (Shader Execution Reordering)

```
问题: RT 着色器中，邻近像素的光线可能命中不同材质/几何，
    导致 GPU warp 内线程发散 (divergent execution)

SER 解决方案: 硬件重排线程执行顺序
  - SM 6.9 / D3D12_RAYTRACING_SHADER_REORDERING_TIER_1
  - VK_NV_shader_execution_reorder
  
用法 (在 ClosestHit shader 内):
  [shader("closesthit")]
  void main(inout Payload p) {
      uint materialID = g_Objects[InstanceID()].materialID;
      
      // 提示 GPU: 按 materialID 重排执行（减少材质着色器切换）
      HitObject::SetShaderExecutionReorderingHint(materialID & 0xF);
      
      // 材质着色...
  }

预期收益: RT 性能 2-3× 提升（在高度发散的场景中）
```

### 7.2 OMM (Opacity Micromaps)

```
问题: alpha-test 几何体（植被、栅栏）在 RT 中产生大量无效 ClosestHit 调用
    - ray 先命中透明像素 → 继续追踪 → 再命中不透明像素
    - 每次命中都需要执行 ClosestHit shader（即使最终会被忽略）

OMM 解决方案: 硬件级预编码透明/不透明区域
  - 离线: 对每个三角形生成 4-state 微图
    state: 0=Opaque, 1=Transparent, 2=UnknownAlpha, 3=UnknownOpaque
  - 运行时: BuildBLAS 时附加 OMM 数据
  - TraceRay: GPU 自动跳过标记为 Transparent 的微三角形
  - AnyHit shader 仅对 UnknownAlpha/UnknownOpaque 区域调用

需要的 Vulkan 扩展:
  VK_KHR_ray_tracing_opacity_micromap (或 VK_NV_ray_tracing_micromap)

预期收益: alpha-test 几何 RT 性能 2-5× 提升
```

### 7.3 RTX Mega Geometry

```
问题: 密集植被/毛发场景中，每帧更新数万个 BLAS 极慢

Mega Geometry 解决方案:
  - 分区 TLAS (Partitioned TLAS): 将 TLAS 划分为多个子树
  - Wide BVH (更宽的 BVH 节点，更高的分支因子)
  - 硬件加速的 BLAS 增量更新

适用场景: 
  - Open World 植被（Nanite 不处理植被）
  - 大规模实例化场景（数十万物体）

约束: 需要 RTX 40+ 系列 GPU
```

## 8. 阶段 F: 神经渲染加速

### 8.1 STBN (SpatioTemporal Blue Noise)

```
蓝噪声特性: 
  - 空间上: 低差异序列（比纯随机更均匀）
  - 时间上: 帧间无重复模式
  - 频谱上: 低频能量为 0（避免可见的结构化噪声）

使用方法:
  1. 离线生成 128×128×64 3D 蓝噪声纹理 (R8G8B8)
  2. 在 Shader 中用 SampleLevel() 采样
  3. 替代所有 Random() / Hash() 调用

示例:
  float2 blueNoiseUV = fmod(
      (float2(idx.xy) + 0.5) / 128.0  // 空间坐标
      + float2(g_FrameIndex % 8, (g_FrameIndex / 8) % 8) / 8.0,  // 时间偏移
      1.0);
  float2 xi = g_BlueNoiseTexture.SampleLevel(g_PointSampler, blueNoiseUV, 0).xy;
  // xi 替代 Random() → 更早收敛 → 更低噪声
```

### 8.2 NRC (Neural Radiance Cache)

```
目标: 用神经网络替代 DDGI 探针网格，提供更高质量的低频间接光照

方法:
  NRC 训练:
    离线: 无（NRC 是在线训练的）
  
  NRC 运行时:
    1. 每帧训练:
       a. 放置探针 (如 32×24 grid = 768 个)
       b. 对每个探针发射 1-2 根路径追踪光线 → 获取辐射度 ground truth
       c. NRC 神经网络训练 1 步（非常轻量，约 0.5ms）
       d. 更新神经网络权重

    2. 推理:
       a. 像素着色时: 查询最近 NRC 探针位置 + 视线方向
       b. NRC 推理 → 该位置的辐射度 (RGB)
       c. 作为间接光照贡献

  NVIDIA NRC SDK: https://github.com/NVIDIAGameWorks/NeuralRadianceCache

  约束: 需要 NVIDIA GPU + Cooperative Vectors (SM 6.9+) 硬件加速
```

### 8.3 NTC (Neural Texture Compression)

```
目标: 8× 纹理 VRAM 节省，同时保持高质量

方法:
  1. 离线: 训练小神经网络压缩每张纹理
     - 输入: 纹理 UV 坐标
     - 输出: RGBA 颜色
     - 网络大小: ~100KB (替代 1MB 纹理 = 10× 压缩)
  
  2. 运行时:
     - RT 着色器中: 在 ClosestHit 时调用 NTC 推理 → 获取纹理颜色
     - 或: 通过 Cooperative Vectors 硬件加速推理

  约束: 需要 RTX 40+ GPU + Cooperative Vectors 支持
```

### 9.1 glTF PBR 扩展支持

在光栅化路径中已支持的扩展需要在 PT 路径中重新实现：

| 扩展 | PT 中的实现 | 位置 |
|------|-----------|------|
| **Transmission** | 透明/折射: BSDF 采样时，以 IOR 决定折射方向 → Refraction Ray | `SampleBSDF()` 中分支 |
| **Volume** | 参与介质: Beer's Law 衰减, 随机弹射距离采样 | `PathPayload` 中加 volumeDistance |

| **Sheen** | 织物微表面: Charlie/Ashikhmin NDF | `EvaluateBRDF()` 中加 sheen 项 |
| **Anisotropy** | 各向异性 GGX: 双粗糙度 (roughnessX, roughnessY) | `D_GGX_Aniso()` |
| **Iridescence** | 薄膜干涉: 波长相关 IOR → 光谱渲染 | 需要 Spectral Rendering 修改 |
| **Specular** | 完整 Fresnel: 有色 F0 + IOR 控制 | 替换 Schlick 为 Exact Fresnel |
| **Dispersion** | 色散: 波长相关折射 → 光谱分离 | 需要 Spectral Rendering 修改 |

实现要点：
- **STBN 绑定铁律**：RT shader 内禁止组合采样器声明（历史坑：破坏描述符集使材质绑定读 0），统一 `Texture3D` + `Load()` 整数坐标（PT rgen b10 / ReSTIR Init b5 / Temporal b12 / Spatial b6）。

- 新增 CVar：`r.PT.Atrous`(true) / `r.PT.Atrous.Iterations`(4) / `r.PT.Atrous.SigmaDepth`(0.05) / `r.PT.Atrous.SigmaNormal`(128) / `r.PT.Atrous.SigmaColor`(0.5) / `r.PT.Atrous.Clamp`(0)。

### 已知问题

1. **本机（Intel Arc B370）驱动编译器崩溃（预先存在，非本规划引入）**：
   - 开启 Vulkan 验证层时，igc-default64.dll 在 shader 编译线程随机 SIGSEGV（HEAD 版本同样复现，崩溃点随机漂移）。
   - 规避：`02.Cube.cpp` 已临时 `enableValidation=false`（附注释）。NVIDIA/其他稳定驱动上可恢复 true。
   - 附带影响：Intel 驱动 RT 管线编译极慢（~20s/个），02.Cube 启动初始化约 80-110s（多次 resize 触发重编译）。
2. ~~**ReSTIR 目标函数不含 albedo/metallic**~~ ✅ **已解决（2026-08-06）**：PT 第 5 UAV 输出 albedoMetallic，三个 `EvaluateTarget` 改用真实材质 BRDF（WRS 对 p̂ 正缩放不变，无偏性保持）。
3. **ReSTIR 估计公式**：最终着色用 RTXDI 规范 `f(y)·W·M/weightSum`（W 为当前像素重评估的目标函数值）。文档 §4.2 Pass 4 的 `W/(weightSum·M)` 公式有误（缺 M 因子，亮度会严重偏暗）——实施时已修正。
4. **PT 模式不渲染粒子**：管线无 ParticleRenderer（纯 PT 参考模式定位）。
5. **02.Cube 默认模式保持 2（HybridRT）**；PT 模式通过 ImGui RadioButton 或 `r.Pipeline.Mode 3` 切换；ReSTIR 默认关闭（ImGui Checkbox / `r.PT.ReSTIR 1` 开启）。

### 与文档设计的主要偏差

| 文档设计 | 实际实施 | 原因 |
|---------|---------|------|
| ReSTIR 三个 Pass 用 token 纹理链强制 RG 排序 | 三个 dispatch 放入**单个 RG Pass** 顺序执行 | CullDeadPasses 对 `writes.empty()` 的 Pass 保留；单 Pass 内提交序保证顺序，无需 token |
| 文档 §4.2 Pass 4 独立 Shade Pass | PT_RayGen 反弹 0 直接读 FinalReservoir + 1 条 shadow ray | 避免重复着色逻辑（与 Level 3 帧图一致） |
| `r.Pipeline.Mode==2` 为 PT | 2 已被 HybridRT 占用，PT 为 **3** | 引擎既有约定（0=Forward 1=Deferred 2=HybridRT 3=PathTrace） |
